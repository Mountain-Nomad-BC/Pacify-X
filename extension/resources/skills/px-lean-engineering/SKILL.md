# PX Lean Engineering

Trace the real flow, query project map/symbols/memory/skills/contracts, reuse an existing owner, prefer native or installed mechanisms, and add only the smallest genuinely new responsibility. Record before/after file, dependency, service, configuration, schema, and abstraction deltas plus runnable evidence. Never remove validation, security, data-loss protection, accessibility, recovery, project isolation, or user-required behavior to make a patch appear smaller.
