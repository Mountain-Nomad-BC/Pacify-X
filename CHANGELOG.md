# Changelog

All notable changes to PACIFY-X are recorded here. The project follows semantic versioning.

## 0.6.3 - 2026-08-03

- Bound release certificates to the annotated Git identity, trusted Ed25519 publisher, exact wheel and sdist bytes, evidence manifest, coverage, SBOM, provenance, toolchain, and platform.
- Added transactional filesystem, recovery, quarantine, event-ledger, memory, session, commissioning, lazy-loading, and projection-rebuild controls with negative and fault-injection tests.
- Added executed branch-coverage policy, exact positive/negative tool certification, split sanitation gates, authenticated scanner intake, and closed-world distribution manifests.
- Added public CI, scheduled assurance, exact-asset release automation, governance files, evidence authority indexing, and an end-to-end quickstart.
- Preserved 0.6.2 and its revocation record as historical, non-authoritative evidence.

## 0.6.2 - 2026-08-03

- Added governed, lazy capability discovery and isolated multi-project commissioning.
- Added deterministic orchestration, scheduling, approval, privacy, memory, evidence, and recovery controls.
- Added exact-tool, Python-surface, structural-integrity, packaging, sanitation, and atomic release certification gates.
- Added public Apache-2.0 licensing and publication metadata for Mountain-Nomad-BC.
- Added a user-focused README, AI operator entrypoint, and read-only first-run tooling assessment.
