# Changelog

## 0.5.0

- Adds a project-owned, hash-linked, metadata-only activity ledger with correlation, task/claim attribution, actor presence, active-operation state, bounded search, and explicit privacy limitations.
- Wires editor, filesystem, terminal, task, test, debug, SCM, extension, PX-launched Codex, and MCP lifecycle observations into a dedicated Activity dashboard.
- Adds `pacify_activity_emit` and `pacify_activity_observability`; all 35 MCP tools now produce start/success/failure trace metadata without capturing tool payload contents.
- Adds pause/resume policy controls, human-readable and machine-readable event inspection, JSON export, responsive/touch-friendly activity views, and regression coverage.

## 0.4.4

- Rebuilds the Knowledge Graph as a navigable workspace with flow/orbit layouts, drag and trackpad panning, touch pinch zoom, Ctrl+wheel zoom, keyboard controls, fit/reset actions, a minimap, and collapsible connection details.
- Adds node/path isolation, directional connection badges, selected-node context, larger touch targets, resize handling, reduced-motion behavior, forced-color support, and a browser-driven interaction regression.

## 0.4.3
