# Decision Wayfinding

Use when the destination is known but the route is not. This is decision discovery, not implementation by default.

Create one canonical map containing destination, standing constraints, decisions so far, unresolved fog, and out-of-scope items. Detailed decisions live in child records; the map is an index.

Ticket types: research, prototype, human grilling, or bounded analysis. Each ticket resolves one decision and fits one session.

Claim before work. Work only the open, unblocked, unclaimed frontier. Closing a ticket must record the answer, evidence, confidence, consequences, and newly exposed decisions. Stop when the route is clear enough to produce a spec or executable ticket graph.

For consequential uncertainty, use `runtime.reasoning_controls.run_independent_hypothesis_panel`. Require two or more isolated observable branch artifacts, distinct evidence where possible, an independent critic, a bounded convergence threshold, and preserved dissent. Never request private reasoning traces or force convergence when evidence independence fails.
