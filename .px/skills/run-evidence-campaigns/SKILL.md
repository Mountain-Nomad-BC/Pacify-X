# Run Evidence Campaigns

1. Inventory the target, version, environment, routes, identities, fixtures, adapters, and evidence store.
2. Define campaign scope, stop conditions, mutation permissions, budgets, and global-versus-campaign decision authority.
3. Run smoke/evidence plumbing before authenticated, heavy, network-active, or destructive profiles.
4. Assign stable run and scenario IDs and propagate them through browser, API, logs, traces, and artifacts.
5. Preserve partial outcomes and checkpoint after each independent scenario.
6. Count pass, fail, blocked, skipped, and uncertain separately; expose eligible and total denominators.
7. Preserve raw failure artifacts before repair or rerun.
8. Link every conclusion to evidence and label campaign-scoped results honestly.

Missing identities, adapters, assertions, traces, or reviewed expected truth are blockers—not passes. Agent opinion and visual appearance cannot self-certify a result.
