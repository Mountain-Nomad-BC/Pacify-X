# Context Handoff Package

Capture only continuation-critical state:
- objective and current phase;
- completed decisions and evidence;
- modified artifacts and working-tree state;
- unresolved questions and blockers;
- exact next action;
- validations run and failures remaining;
- hazards, assumptions, and forbidden actions.

Use stable paths/identifiers and link to the project map. Distinguish verified fact from inference. Include a machine-readable JSON receipt beside the human summary. Never summarize away a known failure.
