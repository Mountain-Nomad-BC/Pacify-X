# Govern Persistent Memory

## Ownership rule

Pacify-X memory, knowledge admission, learning promotion, capability admission, and effect authority remain canonical. The `pacifyx_memory` package is an optional external persistence engine. Its records, graphs, reviews, public projections, promotion receipts, and contributor history are evidence or external state only.

## Wave-10 admitted surface

1. Verify the external package is installed outside the Pacify-X source tree.
2. Bind the call to the exact installed package-tree SHA-256.
3. Require the configured private memory repository to resolve outside the Pacify-X source tree.
4. Allow only `memory.repo.validate`, `memory.record.list`, `memory.review.preview`, and `memory.graph.preview` through `runtime.persistent_memory_provider`.
5. Treat every returned object as noncanonical and `authority_granted=false`.
6. Feed useful findings into existing PX learning/memory review gates as evidence; never copy them directly into canonical memory.

## Deferred external package capabilities

The external package also contains repository initialization, immutable record creation, layer transitions, review persistence, derived graph persistence, contribution bundling/staging/review, external public-memory publication, and public-cache synchronization. These capabilities are intentionally **not exposed through PX in Wave 10**. A later admission must bind each write/network effect to current PX effect-grant and approval evidence.

## Review and graph rules

- Review preview is advisory and must not execute an arbitrary model command.
- Graph preview is derived from immutable records and hash-chained events; unresolved targets remain explicit.
- A review, graph, or external public projection cannot certify truth, grant permissions, admit a skill, or promote learning.
- External provider failure must degrade explicitly; it must not become an empty-success result.

## Private/public boundary

- Private memory is private by default.
- A private repository must not live inside Pacify-X or overlap its public repository.
- Contribution selection is explicit.
- Remote push is explicit and remains disabled through the Wave-10 PX bridge.
- External public promotion is a package-specific publication transition, never Pacify-X canonical-memory promotion.

## Tiny operator role

The resident small model may ask this skill to locate records, summarize advisory review findings, or inspect the derived graph. It may propose follow-up learning or graph/map maintenance to canonical PX workflows. It may not use external-memory content, contributor reputation, or an external promotion receipt as its own authority to write, publish, or change policy.

## Completion

Complete only when exact package revision, repo/PX isolation, malformed/tampered record rejection, event-chain integrity, advisory-only review/graph behavior, import absence, and mutation/publication denial tests pass.
