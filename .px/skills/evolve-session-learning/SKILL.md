# Evolve Session Learning

## Purpose

Convert bounded session evidence into project-scoped candidate knowledge and admitted capabilities.

## Loading rule

Load this candidate metadata only after semantic selection. Load one capability reference at a time. Raw external source material is quarantined as reference-only and must never execute merely because it is present.

## Candidate capabilities

### `observe-project-scoped-instincts`

Capture bounded session observations and derive atomic, evidence-backed candidate behaviors isolated by project before any memory or skill promotion.

**Use when:** repeated corrections should become reusable guidance; project conventions must not leak across repositories; tool traces contain reusable operational patterns.

**Mechanisms:** pre/post action observation; project fingerprinting; atomic trigger-action records; confidence scoring; tail sampling; observer re-entrancy guards.

**Hard boundaries:** no private chain-of-thought capture; no cross-project promotion from one project; observations remain candidate-only; redact secrets before persistence.

**Proposed PACIFY-X owner:** `govern-metacognitive-evolution`

### `evolve-instincts-into-capabilities`

Cluster compatible atomic candidate behaviors, test them against held-out evidence, and propose skills, rules, commands, or agent refinements without self-authorizing activation.

**Use when:** several candidate instincts describe one reusable procedure; a repeated pattern is mature enough for formalization.

**Mechanisms:** confidence decay and reinforcement; cross-project promotion threshold; cluster coherence checks; skill/rule/agent output selection; rollback metadata.

**Hard boundaries:** proposal only until admission; contradictory instincts must not be averaged into nonsense; retain negative evidence and scope.

**Proposed PACIFY-X owner:** `forge-skills-from-knowledge`

## Admission requirements

- Validate behavioral need against the current PACIFY-X owner and semantic index.
- Prefer merging a mechanism into an existing owner over creating a competing control plane.
- Run negative, conflict, rollback, license, and retrieval tests.
- Keep all learned or external content candidate-only until explicit admission.
