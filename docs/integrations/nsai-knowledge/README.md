# Pacify-X NSAI Knowledge Integration

The NSAI library uses one canonical object per JSON file under `knowledge/nsai/objects/`. `knowledge/nsai/index.json` is a deterministic projection and never replaces the individual object files as authority.

## Current corpus

The implementation-wave closure corpus contains 74 canonical objects spanning model runtime/backend behavior, retrieval generations, MoE routing, memory/learning lineage, semantic/LSP intelligence, RIE/Remy operational mechanisms, cognitive generation, bounded librarian selection, durable coordination, context checkpointing and VS Code commissioning.

## Admission lifecycle

`source/provenance -> canonical single-object JSON -> schema/semantic validation -> cross-reference validation -> deterministic index rebuild -> governed retrieval`

Knowledge-object presence grants no execution authority. Runtime-learned/private material remains outside the certifiable source tree until its existing PX review/promotion authority explicitly admits a revision.

## Client behavior

The final client layer may query the library through the existing cognitive/knowledge owners. It does not hydrate arbitrary files or treat similarity/reranking as authority. Stable IDs, revisions, evidence references and lifecycle/privacy filters remain the governing identities.
