# Distribution model

PACIFY-X publishes a lean runtime wheel and a complete source distribution.

The wheel contains the importable `engineering_bootstrap` package, its
`engineering_bootstrap.builders` package, and the contracts, policies,
registries, workflows, templates, skill definitions, skill scripts, and other
assets required by installed commands. It intentionally does not contain the
repository test suite or second source-form copies of `runtime/` and
`builders/` below `share/engineering-bootstrap`. Importable package files are
the sole installed authority for that Python code.

The source distribution contains the authoritative package sources, release
and build controls, and the test suite needed to reproduce and certify a
release. Release-only dependencies remain in the `test`, `build`, and
`release` optional dependency groups; a normal runtime installation has no
dependency on that testkit.

Every source-to-archive projection is generated from `pyproject.toml` and
`MANIFEST.in` by `runtime.release_distribution.generate_artifact_manifest`.
Release builds compare both archives with that manifest, reject missing or
undeclared files, and verify every declared projection against its source
SHA-256. Archive metadata generated by the standardized build backend is
admitted only through the manifest's explicit generated-entry patterns.

Supported releases are bounded to Python 3.11 through 3.14 on Windows, Linux,
and macOS. The canonical matrix is `policies/platform-support.json`; project
metadata, CI, release environment validation, and release certificates must
agree with it.
