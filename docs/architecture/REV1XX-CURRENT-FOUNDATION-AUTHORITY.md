# Current foundation readiness authority

`plan-foundation` independently checks the current non-Git W0 software requirements. The explicit host operation `plan-foundation --reference-root <read-only-corpus> --register-readiness --git-deferral-authority <owner-decision>` registers those checks with normal `plan-readiness`.

The host records actual forward status transitions and immutable current proof images. Its policy-bound registration is separate from the status overlay. Reading an overlay cannot create a host decision or evaluator. Every readiness read invokes the native foundation verifier again and checks the current foundation source revision, exact status image, proof hashes, campaign and ledger binding. Source drift or a native invariant failure blocks readiness. An unchanged repeated registration preserves current transition bytes; an explicit current revalidation retains actual previous images and original transition provenance.

Only BASE-001 through BASE-004 receive this registration. The four Git-specific criteria remain DEFERRED by the owner's explicit campaign decision and cannot become PASS. BASE-001 and BASE-002 can be campaign-conformant only with independently passing current preservation, package-version, decision, terminal-state and release-isolation checks. BASE-003 and BASE-004 require every literal criterion to pass. No W1 or later card receives acceptance from this operation.

Prepared publication images belong to ResourceManager before creation. Current authority/proof/transition files and status projections are operational state, excluded from authored-source census; admitted planning manifests remain authored inputs. Existing historical source/status artifacts remain preserved reference and rollback material. The read-only corpus location is host configuration, while evidence citations use repository-relative, hash-bound artifacts.

This is a software control. It does not authorize builds, installs, Git reconciliation, legal conclusions or certification. The owner's no-build/no-install hold remains active.
