## Graph, Obsidian, 3D and repository deliverables



- [ ] Repair current factual mappings as source behavior changes while retaining the frozen audit as historical evidence.

- [ ] Produce the complete reproducible atlas under `docs/architecture` in the repository: data, tools, vault, offline viewer, evidence manifests and entry documentation.

- [ ] Preserve canonical node/edge/flow IDs across the vault, 3D viewer, metrics, paths and filters.

- [ ] Implement the brain-like navigable structure with meaningful clusters, bridges, deterministic layout and weights whose definitions are visible. Heuristic weight must remain separate from evidence confidence.

- [ ] Complete all 36 standards below, including 11 views, 11 cameras and five lifecycle journeys.

- [ ] Verify actual Obsidian global/local graph navigation and actual browser/3D operation; file/link validation alone is insufficient.

- [ ] Measure baseline/changed build memory/time, layout stability and frame/interaction behavior on the complete graph.

- [ ] Include resource flows for CPU, RAM, disk, GPU, workers, money, tokens, calls, duration and retries, with reserve/consume/reconcile semantics.
