# Decay, revoke and explicitly restore learned knowledge

Promoted knowledge receives cumulative reuse measurements. Decay makes its signed head suspect and computes a supplied dependency cone. Explicit restoration can reauthorize the same canonical identity and retain consumer rebuild obligations.
