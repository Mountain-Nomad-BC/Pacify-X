# Work from request to verified outcome

The bounded single-capability path validates registry and inputs, checks authority, activates one handler, assembles support and evaluates postconditions. Each stage records a checkpoint.

Narrative sequence is not automatically a proven call chain.

This path is currently constrained for non-read effects because its enforce call omits signed grant bindings; its verify call is the compatibility evaluator.
