# Hard-stop state can block an otherwise authorized release transition

**Historical finding; current closure not revalidated.**

recordProgress marks exceeded hard-stop usage as blocked. releaseTask sets task.status to released but preserves that budget/usage. assertBudget requires any hard-stop usage to retain blocked status, so the transition guard rejects that release. This concerns ledger transition consistency, not actual worker termination; no runtime reproduction was performed.
