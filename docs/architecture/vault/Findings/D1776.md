# Native fallback accepts operation type without exact request target

**Historical finding; current closure not revalidated.**

nativeWorkbenchRequestFallbackAdmitted checks request.type and allowed label/type mapping, not a nonempty request ID, target, current terminal state or authority token. After750ms an observed request can trigger keyboard-only fallback even with no visible native blocker. Pure probe accepted permanent-delete mapping with only type. Physical helper PID checks are separate and do not restore missing effect-target binding.
