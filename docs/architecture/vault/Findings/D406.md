# Structural analogy uses degree and relation summaries without node correspondence

**Historical finding; current closure not revalidated.**

Analogy combines relation-label/multiplicity overlap, degree-profile multiset and counts, not graph isomorphism or explicit node mapping. Distinct graphs can share these signatures. Invalid triples and nonmapping candidates can be discarded; a candidate is selected even at zero similarity because there is no abstention threshold.
