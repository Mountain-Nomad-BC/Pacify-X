# Process-tree closure changes meaning without an ownership token

**Historical finding; current closure not revalidated.**

Without ownershipToken reconciliation equates tree closure to worker exit. With a token it scans command-line substring matches, requests termination, then scans once immediately. POSIX termination only sends SIGTERM; it does not await exit/escalate. Command-line token presence is not ancestry or PID-birth proof.
