# Git discovery failure changes mapper corpus and captures before bounding

**Historical finding; current closure not revalidated.**

Git command captures complete stdout/stderr with subprocess.run before checking stdout byte/file limits; timeout is 30 seconds and process is not directly registered with ResourceManager. Any captured-limit/command failure falls back to PX default exclusions, potentially adding Git-ignored paths that are not otherwise excluded. Manifest records fallback and freshness reuses that recorded policy.
