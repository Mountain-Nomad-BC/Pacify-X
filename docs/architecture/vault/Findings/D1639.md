# Canonical memory setup can be partially applied before cancellation

**Historical finding; current closure not revalidated.**

Workspace initialization and discovery can write before project-name/selection dialogs; project creation/activation and workspace config update are separate effects. Later cancellation or memory/refresh failure does not compensate earlier writes. Detach clears workspace configuration but does not itself show an explicit lease-release call in this branch; lease controller handles subsequent state.
