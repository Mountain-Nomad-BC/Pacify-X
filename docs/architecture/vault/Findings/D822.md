# Package read bounds do not create a coherent filesystem snapshot

**Historical finding; current closure not revalidated.**

Traversal checks links and opens bounded regular files using O_NOFOLLOW where available. It compares bytes read with opened size, but no lock binds entire traversal or detects every same-size mutation/ancestor replacement. Root inputs resolved to physical paths before checks; root authority comes from caller.
