# Sanitizer preservation receipt hashes source after copy

**Historical finding; current closure not revalidated.**

Apply creates an empty external preservation directory, scans readable UTF-8 candidates, copies affected files and then hashes/stat-checks each source. It never compares copied destination bytes against the source digest, nor checks immediate source equality before rewrite. Concurrent changes can make preserved bytes and receipt disagree. Preflight errors stop mutation but may leave the created preservation directory.
