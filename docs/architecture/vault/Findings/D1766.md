# Raw asset verification is narrower than complete installed-code identity

**Historical finding; current closure not revalidated.**

The identity enumerates top-level dashboard/src JavaScript and selected fixed assets, excluding generated host code and missing nested CSS/server deployment code. Host manifest hash difference is explicitly intentional because packaging changes main; it needs complementary generated/installed byte provenance, not raw equality. This predicate alone cannot certify all loaded code.
