# Canonical lease maintenance can select a project independently of the visible root

**Historical finding; current closure not revalidated.**

ensureWorkspaceProjectLease accepts the current shared vscode-dashboard session without comparing projectRoot. If selection is needed it prefers one active project over a basename match, then a sole eligible project. Activation and renewal are separate subprocess calls. The host calls this before visible snapshots and on a timer; it therefore has canonical state effects beyond reading the dashboard.
