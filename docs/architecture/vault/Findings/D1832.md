# Protocol fallback can instantiate PX authority and instrumentation twice

**Historical finding; current closure not revalidated.**

A modern discover probe creates a server, and a later legacy opener discards it and constructs another. Factory buildServer recreates authority/instrumentation state. The SDK waits for answered probe requests but does not prove application-owned resource disposal beyond product.close. This matters to future factory side effects and registration ownership.
