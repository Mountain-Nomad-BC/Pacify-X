# Ordinary operational host and bootstrap host follow separate activation routes

**Historical finding; current closure not revalidated.**

Bootstrap-only supplies extensionTestsPath and waits for ready JSON/registered/executed flags. Ordinary host records deferred-to-operational-walker and relies on walker to open dashboard. It waits for CDP and recognized storage first. Native profiles require Windows/cached executable and receive native secret/root/PID; other modes may download pinned host.
