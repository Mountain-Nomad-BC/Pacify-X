# Memory broker receipt authority is scoped to supplied records

**Historical finding; current closure not revalidated.**

Materialization maps supplied records by ID with last duplicate winning, checks metadata predicates and provenance hash shape, then returns a digest. It does not load vault records, authenticate lifecycle history, recompute source bytes or call full MemoryRecord.validation_errors. Future effective times are not rejected by the age comparison; context token count is ceil(serialized item bytes/4), not a model tokenizer.
