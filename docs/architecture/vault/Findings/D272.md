# Recovery compensation does not span final preservation and evidence

**Historical finding; current closure not revalidated.**

After prepared-copy verification and replacement, recovery leaves its try block before moving rollback artifact into quarantine and publishing event/commit. Failures there do not restore old destination. Existing interrupted transaction restores rollback only when destination absent, then escalates even if no restoration occurred. With no previous destination, a failure after replacement can retain the new file. Commit replay checks marker presence and destination hash without authenticating marker body.
