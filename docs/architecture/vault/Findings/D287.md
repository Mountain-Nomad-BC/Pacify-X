# Canonical browser trusts active sessions and shadows source filter output

**Historical finding; current closure not revalidated.**

browse_canonical_memory has no caller actor/session argument; it searches each active session as its stored agent, allowing same-project multi-session duplicate rows. It loads/inspects up to 10,100 ranked results per session before global pagination. Local source variable is overwritten with a record source mapping, so returned filters.source can cease to be the requested string although wanted_source filtering uses the original normalized value.
