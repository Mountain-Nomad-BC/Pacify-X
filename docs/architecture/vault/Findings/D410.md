# Cognitive index validation does not validate every referenced asset

**Historical finding; current closure not revalidated.**

Validator rebuilds and compares index, detects dangling target keys and reports unresolved dependencies without failing them. It does not rehash each supplied body digest, require source/implementation paths to exist/contain root, reject source-edge omissions or validate cycles/status semantics. Tolerant nested JSON readers can skip malformed assets. Standalone builder rebuilds twice then directly overwrites output without atomic publication.
