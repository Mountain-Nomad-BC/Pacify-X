# Readiness version parsing is a bounded numeric subset

**Historical finding; current closure not revalidated.**

First numeric substring supplies three-part version and ignores prerelease semantics. Caret ceiling always increments major, so zero-major constraints differ from full semver. Alternatives short-circuit, potentially leaving unsupported later alternatives unexamined. This is local comparison logic, not package-manager resolution.
