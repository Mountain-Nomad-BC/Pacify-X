# Extension restoration has a narrower guard than disposal

**Historical finding; current closure not revalidated.**

restoreUnchangedStage checks stage/plain-directory, original absence and matching inventory, then renames. It receives no root guard and does not repeat ancestor containment or reserve the absent original destination. A concurrent path/ancestor change can invalidate those checks before rename. Failed quarantine verification after a successful move can also leave an unrecorded quarantine location while stage-based restore finds nothing.
