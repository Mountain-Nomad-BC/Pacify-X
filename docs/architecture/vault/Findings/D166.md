# A rejected WAL commit can still finish previous transactions

**Historical finding; current closure not revalidated.**

commit calls _recover_locked before before-image validation, optional precommit validation and reused transaction-ID rejection. Old pending transactions may therefore be rolled forward/archived even when the requested new transaction later fails. Reusing an ID is rejection, not an idempotent successful result.
