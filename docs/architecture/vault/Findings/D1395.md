# Certifier hashes evidence before later replacing it

**Historical finding; current closure not revalidated.**

Evidence cards inspect and hash their target before apply may regenerate pack evidence. First application cannot create a missing target and count it in the same preceding check; existing recorded hashes can describe bytes replaced later. Invalid cards are not reset from a prior implemented_verified state, so persisted states can disagree with fresh counters.
