# Quarantine verifies known files rather than exact current tree equality

**Historical finding; current closure not revalidated.**

quarantine_candidates inventories files once and rehashes those known entries before moving each candidate. New directory members and empty directory changes are not added to that comparison. expected_sha256 is optional and partial; the stream wrapper omits it. This function does not implement two matching full-tree snapshots or a fresh exact pre-move denominator.
