# Scanner aggregation can lose malformed finding rows without an error

**Historical finding; current closure not revalidated.**

Non-dictionary findings are skipped, but a nonempty all-invalid list suppresses the empty-summary fallback and yields no records. Non-object JSON roots can raise AttributeError outside the catch. Tool/location strings remain raw while messages are hashed; hashing messages alone is not general payload sanitization.
