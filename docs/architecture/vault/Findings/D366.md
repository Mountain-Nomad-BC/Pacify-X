# Canonical authority and browse labels have limited enforcement scope

**Historical finding; current closure not revalidated.**

resolve_canonical rejects suspect or revalidation_required true, but does not require authoritative true or a recognized current status and trusts the signed revision locator without a local semantic identity/containment recheck. Browse derives authoritative from status alone and returns bounded subsets with no pagination. read_only constructor mode avoids initialization but is not retained as a mutator prohibition.
