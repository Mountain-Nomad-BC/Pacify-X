# Drift and health comparisons lack finite-value guarantees

**Historical finding; current closure not revalidated.**

Identity is exact supplied field equality without identity provenance. Personality compares baseline traits only, ignoring extras; NaN differences do not exceed tolerance. Drift assigns missing/mismatched vectors score1, but threshold1 accepts them. EKG NaN values do not trigger comparisons, so a nonfinite metric can appear healthy. These helpers do not collect runtime measurements.
