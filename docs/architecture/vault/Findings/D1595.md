# Native input result is correlated but not authenticated

**Historical finding; current closure not revalidated.**

Client accepts schema, exact request ID/sequence, sent status, positive foreground PID, owned_process=true, expected key count and boolean focus_recovered. It does not verify signature, process ancestry itself, timestamp freshness or result file link/size identity. A writer inside the result directory can supply these assertions; directory custody is therefore the trust boundary.
