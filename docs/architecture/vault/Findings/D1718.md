# Post-worker failures can bypass cleanup and final receipt

**Historical finding; current closure not revalidated.**

After runOwnedHostWorker returns/releases its lease, owner reads child/fixture JSON and hashes source without an encompassing finally. Parse/hash failures occur before settleOwnedEphemeralCleanup. Successful cleanup removes temp root before final wx report write, so a report collision can lose the child evidence kept only there. Final worker assertion also occurs after report publication.
