# Agent terminal state can precede its signed run receipt

**Historical finding; current closure not revalidated.**

Host completion and governed callback execution publish terminal durable state before signing and writing the final run receipt. Signing or receipt publication failure can therefore leave terminal state without that artifact. Host preparation has explicit best-effort compensation for preparation failure; these later commit boundaries are different.
