# Semantic required and excluded context are declarations in reviewed retrieval paths

**Historical finding; current closure not revalidated.**

Envelope validates and preserves required_context/excluded_context, but semantic_query_signals takes only query/envelope and uses keys, aliases, tags, entities and predicates. Reviewed vault candidate search, workspace ranker and memory materializer do not evaluate these context maps. Invalid nonmapping context inputs are also normalized to empty objects by mapping conversion.
