# Dependency additions do not update candidate capability coverage

**Historical finding; current closure not revalidated.**

optimize_candidate_package updates covered during greedy selection, then appends admitted dependencies without updating covered. Consequently covered_capabilities describes the greedy selection, not necessarily the union of the final package. For example, a selected candidate satisfying required X can pull in a dependency offering additional Y while the report still lists only X. This is source-derived accounting behavior, not an executed product test or a demonstrated false-incomplete result.
