# Disabled workflow edges and continued failures change dataflow differently

**Historical finding; current closure not revalidated.**

A required port with incoming but no enabled edge becomes skipped only if no explicit input supplied it. Explicit input can satisfy disabled-edge port; enabled upstream value overwrites explicit input. Skipped or failed-continued nodes retain empty result maps and count completed, allowing downstream readiness while missing source ports can still fail later.
