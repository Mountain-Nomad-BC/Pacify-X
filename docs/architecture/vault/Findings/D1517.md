# Nested cache moves can invalidate expected destination layout

**Historical finding; current closure not revalidated.**

Targets sort deepest-first. Moving an inner cache creates its destination parent; later moving the outer cache to that existing parent makes shutil.move append the source basename. Recorded expected paths can then fail reconciliation after earlier effects. An isolated unchanged-stdlib probe confirmed existing-directory destination behavior with rename intercepted; no directory was moved.
