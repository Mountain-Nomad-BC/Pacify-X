# Graph path and overview do not enforce returned node and edge caps

**Historical finding; current closure not revalidated.**

query_graph computes bounded_nodes/bounded_edges for all modes, but overview returns every cluster and aggregate edge, and path performs unrestricted BFS over the loaded graph then returns the entire found path. Both report limits and truncated false. Full mode independently pages nodes/edges so one edge page may reference nodes absent from the current node page. Neighborhood has separate explicit depth/node/edge enforcement.
