# Behavior metadata extraction has explicit lexical coverage limits

**Historical finding; current closure not revalidated.**

JS/TS regexes omit many arrow/property/method forms; PowerShell matching is line-based; Markdown frontmatter is a simple single-line name/description regex. Symbols/tests are truncated to500 and headings100 without a truncation receipt. Whole-text substrings detect effects without resolving actual calls, and can count comments or miss equivalent syntax.
