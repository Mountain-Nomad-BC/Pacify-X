# Import graph resolves first matching ancestor rather than most specific module

**Historical finding; current closure not revalidated.**

For each candidate, next module satisfying equality-or-prefix is selected in insertion order. A package ancestor can be chosen before exact submodule. From-import aliases are not expanded into submodule candidates, and package __init__ relative context uses parent calculation. Cycle graph therefore approximates actual imports.
