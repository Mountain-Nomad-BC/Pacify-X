# Generated calculation identifiers are not fully validated

**Historical finding; current closure not revalidated.**

Compiler checks the slugged function name with isidentifier but not reserved keywords; supplied variable names are joined directly into both function signatures without unique/identifier/keyword validation. AST validates names used in the expression, leaving unused declared variables outside that check. Compilation can return malformed generated source; later candidate certification only parses Python.
