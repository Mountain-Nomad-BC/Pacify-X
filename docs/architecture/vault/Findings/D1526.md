# Identifier audit file and byte counts include unscanned binary contents

**Historical finding; current closure not revalidated.**

Known binary suffixes bypass content scanning but add stat size to bytes_scanned. Unknown suffixes are fully decoded once for classification, then read again for scanning if admitted. Unknown-suffix OSError/UnicodeDecodeError returns false rather than recording the error; an isolated unreadable-file probe confirmed this classification result. Counts are visited/stat-accounted bytes, not universally inspected content bytes.
