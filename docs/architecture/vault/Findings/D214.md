# Capacity ledger corruption can erase accounting and crashes can retain leases

**Historical finding; current closure not revalidated.**

PlacementCapacityLedger._read maps OSError/JSON error or malformed active container to empty state. Reserve can then overwrite with new accounting. Normal reserve/release is locked, but leases have no owner PID, expiry, heartbeat or restart recovery; a dead callback owner can retain reservations indefinitely. Matching groups omit device_index.
