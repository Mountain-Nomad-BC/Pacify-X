# Sort sample bounds do not bound total parsing work

**Historical finding; current closure not revalidated.**

Reservoir record count is bounded, but the entire source stream is parsed and type-checked and later fully hashed. A single huge record or incomplete JSON value can grow the buffer without a byte limit. No input size, deadline or candidate timeout is enforced.
