# Bayesian dependence damping depends on caller order and overrides

**Historical finding; current closure not revalidated.**

Within a declared group, default weights are1/sqrt(n) in input order, so exchanging unequal likelihood records changes their influence. Caller dependence_weight may override to1 for each. Zero prior/likelihood remains impossible, and all-live-zero evidence correctly rejects. These are declared-likelihood updates, not learned dependence estimation or evidence authentication.
