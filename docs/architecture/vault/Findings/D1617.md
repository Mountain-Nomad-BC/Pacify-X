# Host input scope relies on heuristic locator discovery and a pathname interval

**Historical finding; current closure not revalidated.**

Keys ending in path/file/folder/directory/root/cwd/target/source/resource/uri/url or path-shaped strings trigger scope checks; ordinary strings may pass unchanged. Existing ancestor realpath is joined with nonexistent suffix. A path can change after check and before tool use. These are input normalization boundaries, not stable opened handles.
