# Lock hash count does not prove unique artifacts for every platform

**Historical finding; current closure not revalidated.**

Dependency audit counts --hash=sha256 marker occurrences and compares counts to Python/OS matrix sizes. It does not validate digest syntax/uniqueness or bind each hash to a platform wheel. Requirement names are parsed by equals splitting and workflow authority by substring checks. Actual package installation and resolved dependency closure are outside these checks.
