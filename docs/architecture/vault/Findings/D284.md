# Workspace preview and idempotency do not precommit an operation

**Historical finding; current closure not revalidated.**

run_workflow_request returns preview before payload shape/path/timeout checks. It writes idempotency receipt only after handler returns, so failure before receipt publication permits retrying effects. Existing receipt replay compares request hash and trusts recorded result; it does not verify checkpoint hashes, current handler revision or receipt authentication. Current active session is required before replay.
