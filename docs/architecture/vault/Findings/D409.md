# Cognitive dependency and alias resolution have different ambiguity rules

**Historical finding; current closure not revalidated.**

Dependency edges use explicit reviewed mappings or one unique exact/normalized identity, otherwise retain unresolved. Alias-to-leaf helper mapping overwrites normalized collisions before applying aliases. Target project/metacognitive capability records retain dependency/formula fields without creating corresponding edges, so hydration can omit those declarations. Explicit reviewed status is a string, not authenticated review evidence.
