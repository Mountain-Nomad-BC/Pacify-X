# Cognitive freshness validation is confined to status in the CLI

**Historical finding; current closure not revalidated.**

All cognitive actions load the index, but only status calls validate_cognitive_index and integration_healthcheck. Query and hydrate-plan use the loaded index directly; run also requires the index file even though dispatch uses a separate facade. Agent list valid is based on matches before limit, so limit0 can return valid=true with no agents.
