# Graph identity ignores labels weights and rendered attributes

**Historical finding; current closure not revalidated.**

graphProjectionIdentity hashes sorted node keys and edge source/relation/target triples. Labels, node/edge weights, other attributes and layout are excluded, while empty graphs/duplicate IDs and inconsistent total counts are not fully rejected. Pure probe changed labels and weights without changing identity. This matters directly to the requested weighted navigable map.
