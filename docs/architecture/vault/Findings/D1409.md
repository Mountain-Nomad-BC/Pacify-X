# Model parameter estimates are a simplified dense formula

**Historical finding; current closure not revalidated.**

Parameter count uses standard attention projections, two or three FFN matrices and embedding/norm assumptions. Expert count changes only an active fraction, not total FFN weight parameters. Unknown activation is treated as gated, and truthy tie_word_embeddings strings affect embedding count. These are estimates, not a loaded-model inventory.
