# Publication workflow tests inspect local strings and retained bindings

**Historical finding; current closure not revalidated.**

Workflow ordering, OIDC, exact VSIX values and manual transport are checked as strings, not parsed/executed CI behavior. User-reported marketplace publication remains a separate fact.
