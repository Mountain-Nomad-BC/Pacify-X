# Healthy loopback response is not bound to the owned server process

**Historical finding; current closure not revalidated.**

Health accepts a 2xx response at the chosen port while spawned process poll remains None, without checking socket ownership, loaded model or server session. A different listener can satisfy this check. Readiness and inference openers disable proxies but retain standard redirect handling; final response origin is not revalidated here.
