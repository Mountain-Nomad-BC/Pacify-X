# Two generated graph APIs use incompatible edge keys

**Historical finding; current closure not revalidated.**

generated_dependency_graph emits source/target edges. adapt_generated_dependency_graph reads only from/to, silently skipping records without both keys; its test explicitly supplies from/to. Directly composing these two APIs would therefore produce no adapted edges or nodes. This is a source-derived contract counterexample, not a claim that a production caller currently makes that direct call.
