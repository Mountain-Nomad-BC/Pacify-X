# Summary publication release finish and repair advance are separate effects

**Historical finding; current closure not revalidated.**

Exclusive prepared summary publication uses a prior existence check then replacement; concurrent target creation can race that check. Finish runs before a separate repair-state rewrite. Finish or advance failure is not rolled back by this owner, and advance does not use a shared predecessor-bound transaction with the release stage.
