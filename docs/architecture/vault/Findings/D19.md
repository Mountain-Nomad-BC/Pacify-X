# Canonical and certified are scoped terms

**Historical finding; current closure not revalidated.**

Transcript canonical records mean schema-conformant extraction records; Memory Vault admission, signed Knowledge Core heads and Skill Studio canonical bytes each have different owners. Skeptical assurance certified is a metadata-based policy result; a release certificate has separate artifact and operational requirements. Reusing the words across these boundaries would hide material differences.
