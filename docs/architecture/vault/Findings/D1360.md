# Incomplete review matching validates labels rather than the review condition

**Historical finding; current closure not revalidated.**

Reviews bind ID/path/rule while ignoring line movement, require an allowed class plus nonempty rationale/condition, and reject stale IDs. They do not evaluate review_condition, verify an accountable owner or bind whole source bytes. A same-ID new pass site can inherit an earlier classification because of the context-free ID.
