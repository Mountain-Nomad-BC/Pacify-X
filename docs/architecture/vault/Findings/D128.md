# Active memory index and canonical search are separate paths

**Historical finding; current closure not revalidated.**

Index validation checks entries against all historical records, without requiring every latest record to be represented. Reconciliation selects generation from retained activation events but does not compare event manifest_sha256 with current validated manifest. Direct vault.search reads canonical eligible records and workspace search uses a separate ranker; neither consults active index entries.
