# Filesystem walk limits exclude directory count and pre-limit listing memory

**Historical finding; current closure not revalidated.**

bounded_walk materializes/sorts each directory before checking per-entry file/depth/stat-byte limits, and has no directory count or global time cap. Link policy uses DirEntry.is_symlink without explicit all-reparse classification. Returned logical paths are opened later by consumers, so containment checks do not pin later file identity. Positive limits are not strict integer/finite validation.
