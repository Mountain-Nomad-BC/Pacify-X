# Chat participant model execution is a separate authority and budget route

**Historical finding; current closure not revalidated.**

Status/skills/context commands do not invoke a model. Ordinary prompt uses request.model supplied by VS Code, checks input against maxInputTokens, streams text and records provider activity as effect observe. It does not call the Studio model selector/tool policy/output budget or a local timeout, and does not consult the imported provider policy report here.
