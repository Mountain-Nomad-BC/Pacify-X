# Reference selection and ledger binding have different containment rules

**Historical finding; current closure not revalidated.**

Quality helper permits absolute existing paths and strips the final colon suffix heuristically; generic ledger evidence binder hashes only resolved contained files. A helper-selected external path can therefore remain unbound. Fallback ledger file is mutable and each independently committed chunk may bind a different prefix.
