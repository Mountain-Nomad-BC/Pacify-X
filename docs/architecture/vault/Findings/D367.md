# Summary cursor consumes omitted facts and does not enforce terminal closure

**Historical finding; current closure not revalidated.**

summarize stops selecting at max_facts but advances end_event_id across every pending event. Later calls cannot recover omitted later facts through this cursor. Source hash excludes created_at; SessionEnd only marks final when it is last, and later events after a final record are still accepted. Number allocation and cursor read have no common lock or history authentication.
