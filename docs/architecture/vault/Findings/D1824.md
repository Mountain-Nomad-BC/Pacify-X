# SDK cancellation signal is discarded before PX handler execution

**Historical finding; current closure not revalidated.**

executeToolHandler invokes executor(args,ctx), but mcpActivityIntegration returns async(input) and calls handler(effectiveInput). ctx.mcpReq.signal and exact transport request identity never reach PX handlers. Synchronous spawnSync can also block receipt of cancellation; SDK aborted replies do not roll back already executed effects.
