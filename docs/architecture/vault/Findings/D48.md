# Lifecycle process completion is a metadata presence check

**Historical finding; current closure not revalidated.**

record_process_candidate optionally writes a process receipt and appends its relative path to evidence.process_records. lifecycle_status marks process-capture complete from bool(process_records). It does not resolve those receipt bytes in that stage check. Verification-stage checks also distinguish a few sentinel statuses rather than independently rerunning verification. This metadata router must not be treated as a release certificate.
