# Closed-card outgoing handoff condition does not count prior handoffs

**Historical finding; current closure not revalidated.**

Validator allows a closed active card when previous checkpoint has same active gap and switching_to is nonempty. It does not reject a second same-card outgoing checkpoint after the first. The test checks absent target, refusal of new work and one valid switch, not repeated outgoing emission.
