# Project event append can publish event before protected head fails

**Historical finding; current closure not revalidated.**

Failure in later phase leaves event/head mismatch, and next append refuses invalid ledger. Readers do not hold append lock. Adjacent authority is a filesystem trust location, not signed host identity or ACL setup enforced by this module.
