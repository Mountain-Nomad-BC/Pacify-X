# Skill identity joins use metadata rather than body equivalence

**Historical finding; current closure not revalidated.**

Inventory and structured-text IDs are dictionaries with last duplicate wins. Canonical identity uses frontmatter name or parent path and catalog name membership, ignoring source body, catalog state and package hashes. A root SKILL.md without a name can raise IndexError. Completion compares matched metadata count with deduplicated skill count.
