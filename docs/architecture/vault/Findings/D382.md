# Foundry bundle identity does not commit all generated artifacts

**Historical finding; current closure not revalidated.**

compile_foundry_bundle hashes only source records and merged knowledge. Calculations, registry capability exclusions, emitted skills/schemas/benchmarks and compiler revision do not enter bundle_id. Distinct outputs can share destination identity; materialization rejects any existing directory instead of reconciling it.
