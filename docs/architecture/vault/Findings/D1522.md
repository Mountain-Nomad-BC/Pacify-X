# Sanitizer rename resolves links before applying the operation

**Historical finding; current closure not revalidated.**

_extended_windows_path calls path.resolve for source and target, and _rename passes those resolved paths directly to os.rename. The owner does not reject symlink files or recheck resolved containment. An unchanged-function probe with fake resolution confirmed that an in-tree logical link resolving outside would pass the outside target as rename source; actual links/moves were not created.
