# Stdout backpressure and close have no aggregate deadline

**Historical finding; current closure not revalidated.**

StdioServerTransport.send waits for drain/error after a false write result without a timeout. closeAll awaits subscription writes, product.close and wire.close without an aggregate bound. Application shutdown ownership cannot be inferred from a bounded inbound frame size or3-second probe-answer wait.
