# Map replacement and final receipt are separate publication boundaries

**Historical finding; current closure not revalidated.**

After staged validation, builder moves old output into history, then moves stage into output, then rewrites promoted receipt in place. If new promotion fails, old output is not restored; if receipt write fails, new output already exists. Exception path preserves remaining stage but not an atomic rollback. Exclusive lock uses file existence with no liveness recovery and is written before the main try/finally.
