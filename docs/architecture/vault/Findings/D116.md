# Missing capability graph can appear as available empty graph

**Historical finding; current closure not revalidated.**

Repository view returns available false for missing, oversized or invalid source. Capability view uses _read_json(...,{}) and then empty records/edges on missing or malformed JSON; later empty-selection response reports available true. Neither branch verifies a projection-staleness marker in query_graph. Unavailable source and a valid empty capability graph are not distinguished by that path.
