# Fault acceptance can use an unrelated or hidden alert

**Historical finding; current closure not revalidated.**

failureContained accepts nonempty alert text even if exact control text is unchanged. The collector uses allTextContents across alert/loading/empty selectors without a visibility or control-association check. Therefore unrelated/hidden fallback text can credit containment. Disappearance and changed text also lack semantic error-state validation.
