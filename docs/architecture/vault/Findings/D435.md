# Lineage and six-axis gates have separate unchecked policy inputs

**Historical finding; current closure not revalidated.**

Lineage checks exact origin/authority/visibility labels and nonempty source_refs without authenticating them; omitted authority/visibility can avoid rejection. assurance_score rejects NaN axis values through range checks but does not validate minimum_axis, so NaN or negative threshold can bypass intended minimums. Numeric string axes can pass float range checking yet fail the later raw-value comparison.
