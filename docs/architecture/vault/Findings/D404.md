# Decision scores depend on supplied feasibility and candidate population

**Historical finding; current closure not revalidated.**

Constraints are trusted violation lists, not evaluated predicates. Metrics normalize over all eligible candidates, so adding an alternative changes utility scales. A sole candidate gets a regret bound from its own best-minus-worst interval. No-eligible early return skips weight/posture validation and hash. NaN weight can be clipped to zero before finite checking; very large finite aggregates can overflow.
