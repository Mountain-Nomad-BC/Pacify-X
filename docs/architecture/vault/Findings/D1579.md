# Missing operational owners are subtracted twice

**Historical finding; current closure not revalidated.**

The duplicate filter selects any owner count other than one, including zero, while missing selects zero separately. owned_once subtracts both lengths. An unchanged-source VM with one unowned filesystem-write control reports total=1, owned_once=-1 and the same control in missing/duplicate. Exit remains correctly nonzero.
