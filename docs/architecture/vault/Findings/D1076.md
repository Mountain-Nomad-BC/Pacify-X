# Source limit is defined on an unused export helper

**Historical finding; current closure not revalidated.**

The 128MiB limit is enforced by _snapshot, which actual create_clean_export does not call. Actual materialization copies then hashes staged files without that aggregate limit. _snapshot also reads source twice, so its two digest fields would not be an atomic snapshot even if used.
