# Host cache metadata contains more than its read gate checks

**Historical finding; current closure not revalidated.**

MetadataCache.set records dependency_fingerprints, but get checks the supplied source fingerprint and maximum age; it does not compare each dependency field. PxBridge separately propagates revisions, clears request caches and incorporates revision fingerprints into some keys. Correct cache use depends on that caller wiring.
