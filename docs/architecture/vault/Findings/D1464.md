# Visibility ingress chooses its allowed root from caller bus location

**Historical finding; current closure not revalidated.**

The CLI resolves --bus-root, chooses its parent as allowed_root and creates that directory before constructing OperationalEventBus. This is a caller-selected publication boundary, not containment under the framework root. Batch validity does not independently confer event authority; the downstream bus owns its checks.
