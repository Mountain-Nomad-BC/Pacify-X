# Workflow effect fields are not an aggregate execution ledger

**Historical finding; current closure not revalidated.**

Run receipt initializes attempted/completed/denied effects empty and effects_executed false, without updating them as supervised workers run. Worker likewise emits empty effect lists despite arithmetic/sleep and process activity. Declared grants are metadata; the actual adapter set is identity/increment/double/fail/sleep and does not dispatch arbitrary declared capabilities.
