# CSS deduplication does not compare declarations

**Historical finding; current closure not revalidated.**

The rewrite removes a legacy branch whenever its normalized selector/scope key exists in modular CSS. A pure probe with legacy red text plus white background and modular blue text in another layer removes the entire legacy rule, including unmatched background. This is selector migration, not proof of equivalent computed styles.
