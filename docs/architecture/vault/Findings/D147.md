# Resume observer handoff is run-bound rather than launch-generation-bound

**Historical finding; current closure not revalidated.**

launch_studio_worker reuses sessions/run_id/worker-request-cleanup.json across resumes. Observer waits only for its existence, and finalizer filters worker history by the retained resource/PID when present. Until the new worker overwrites it, an old binding can identify an exited prior worker. Path reconciliation also returns early when multiple historical worker records share the run. This race requires a targeted reproduction before claiming an observed premature terminal transition.
