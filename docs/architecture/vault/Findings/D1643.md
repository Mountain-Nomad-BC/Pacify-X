# Lifecycle refresh can hide a completed manager receipt

**Historical finding; current closure not revalidated.**

Native install/update/uninstall/rollback and environment move/restore await refreshEnvironment after action but before posting result. If discovery/publication fails, outer operationError follows the completed effect and the manager receipt may not reach that webview. Recovery should inspect authoritative manager state rather than infer no effect from reply error.
