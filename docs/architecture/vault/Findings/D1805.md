# Sidebar bounded journals use length offsets that stop advancing at capacity

**Historical finding; current closure not revalidated.**

Full snapshots are capped at20 and outbound requests at80, but subsequent scenario waits use previous array length and slice offsets or require length growth. At capacity new entries cannot increase length, so new evidence is missed or recovery times out. Synthetic snapshots also enter the same host journal.
