# Index publication and source identity are separate observations

**Historical finding; current closure not revalidated.**

Engine identity hashes a filtered sequential tree, excluding mutable state/evidence and other named families. Index reads stat/hash/parsed metadata separately and publishes registry then versioned projection through fixed prepared filenames without shared lock/WAL. Invalid index is still publishable; failure or concurrent writers can leave projections different.
