# Project call resolved flags encode lexical guesses

**Historical finding; current closure not revalidated.**

_call_graph indexes each file by short symbol name, overwriting equal method names, and resolves callee leaf against local or imported symbols without receiver binding. Unresolved plain calls often do not enter external summary. Python relative imports from __init__ lose package context, JS relative resolver does not collapse parent segments, and duplicate Python module paths can overwrite via set iteration. These limits propagate into impact and test associations.
