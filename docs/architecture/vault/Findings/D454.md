# Head and replay have different integrity and concurrency limits

**Historical finding; current closure not revalidated.**

head holds publish lock, recovers WAL and validates current anchor/state/event plus preceding event digest, not complete ancestry. replay recovers without publish lock, scans all events and can race publication. If no event files exist, replay skips state/head consistency even with nonzero state; head revision0 checks head presence but not orphan event files. Anchors are unkeyed local JSON rather than an external trust root.
