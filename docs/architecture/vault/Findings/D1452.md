# Group reruns do not invalidate prior group receipts before execution

**Historical finding; current closure not revalidated.**

Unlike sections, execute_group checks index freshness, runs the child, then writes the group receipt. A failure before that write can leave an older passing receipt untouched. Direct run can select an already current group, so interruption semantics differ between group and section owners.
