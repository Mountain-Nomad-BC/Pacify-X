# Cohesion WAL validates after-images without a planning predecessor

**Historical finding; current closure not revalidated.**

Cards/evidence/state are read and projected before commit. JsonWal captures before-images under its own lock; custom precommit reads transition.after only and does not compare transition.before with the previously validated planning snapshot. A concurrent valid change before lock acquisition can be overwritten by the older proposal while still becoming the transaction before-image.
