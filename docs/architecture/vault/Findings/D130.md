# Three retrieval paths have different filters and scoring

**Historical finding; current closure not revalidated.**

Vault search uses candidate_memories exact semantic/SimHash selection then structured/lexical/relationship scoring. Workspace search first checks lease and actor, obtains vault retrieval_records, and calls rank_memories with lexical and optional caller scores/fixed bindings. Generic retrieve uses seven fixed weighted signals and visibility. Its strategy is a label and its byte counter includes excerpts only. No shared ranking equivalence is established by their names.
