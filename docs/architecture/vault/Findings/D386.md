# Generated calculation functions omit interpreter runtime controls

**Historical finding; current closure not revalidated.**

evaluate_calculation checks numeric nonboolean finite inputs, exact variable set, AST64/depth16, magnitude1e100 and exponent16. Emitted Python directly returns the expression and JavaScript directly evaluates it with a modulo helper. Neither emitted function contains these guards; JavaScript division by zero and overflow differ from interpreter rejection. Tests inspect strings and execute only the interpreter.
