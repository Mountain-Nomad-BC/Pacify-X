# Observation time fallback can follow filesystem rewrite time

**Historical finding; current closure not revalidated.**

Valid timezone-aware receipt times are preserved; malformed/naive/missing times fall back to file mtime. Rewriting or touching old evidence can thus advance fallback observation time. Builder does not reject future/stale timestamps; optional coverage enforces age/future bounds separately.
