# Lifecycle recovery is roll-forward rather than reader-atomic publication

**Historical finding; current closure not revalidated.**

Canonical directory is displaced/replaced and verified before _bounded_lifecycle_artifacts validates all images. Artifacts then publish individually, including receipt in sorted path order, before final committed manifest. Corrupt image or conflicting projection can leave changed canonical with incomplete projections and an applying journal. Tests exercise synchronous exceptions and successful restart with intact custody, not actual process-kill at every boundary.
