# Packaging path emission relies on trusted filenames and overlays

**Historical finding; current closure not revalidated.**

File values and destinations are quoted by interpolation without TOML escaping. Logical overlay names are unvalidated; external staged paths can fail root-relative sorting. Canonical native root symlinks rejected, but facade directories lack same root check. No bounded enumeration or hash attestation is performed by renderer.
