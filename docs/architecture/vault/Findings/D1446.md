# Stale-group child timeout expands to cover the full queue

**Historical finding; current closure not revalidated.**

Refresh finds noncurrent groups, requires each in registered topology and uses max(requested timeout,sum group timeouts plus max60 or15 seconds per group). It launches one owned run-stale child with three workers and aggregate disk budget. This is intentionally larger than a single profile budget, not a global wall-time cap shared with the subsequent coexistence run.
