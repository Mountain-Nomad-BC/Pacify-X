# Schema constant and uniqueness checks use different Python comparisons

**Historical finding; current closure not revalidated.**

Instance const/enum use Python equality, where boolean True compares equal to numeric 1; uniqueItems compares JSON-serialized representations, distinguishing numeric 1 and 1.0. Explicit integer type rejects booleans, as tested, but that does not change const/enum rules without such type constraints. Unruled additional values are not recursively checked for nonfinite or non-JSON Python values.
