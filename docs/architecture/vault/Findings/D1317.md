# Heuristic catalog does not retain a complete discovery error denominator

**Historical finding; current closure not revalidated.**

Catalog prunes named dependency/build directories, silently continues on stat/read failures and uses os.walk without onerror. It emits no file hashes. Its file_count is successful selected rows rather than all physical files. Optional summaries read at most nominal 1 MiB files but only return a short heuristic description.
