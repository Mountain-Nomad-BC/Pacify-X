# Cancelled half-open circuit trial can leave admission closed indefinitely

**Historical finding; current closure not revalidated.**

_admitCircuit sets halfOpenActive true after cooldown. _recordCircuit returns immediately for cancelled work, leaving that flag set. The next call rejects whenever halfOpenActive is true, with no later cooldown transition clearing it. Queued cancellation/displacement also lacks that reset, unlike explicit queue-full rejection. The existing half-open test covers success, not cancellation; this is source-derived, not a live incident reproduction.
