# Project-map query freshness depends on its caller

**Historical finding; current closure not revalidated.**

query_project_map directly reads retrieval index and manifest with a path/mtime/size cache and does not verify sealed artifact hashes or current source tree. CLI query calls it directly. route_task separately validates freshness first, then queries and rereads manifest; those separate reads are not sealed into one immutable revision. Stat-preserving replacement can reuse cached metadata.
