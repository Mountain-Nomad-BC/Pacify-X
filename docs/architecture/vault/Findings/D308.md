# Active skill cache does not upgrade references or recheck current source

**Historical finding; current closure not revalidated.**

hydrate returns active entry immediately by ID, even when a later request enables references or source/status changed. unload can remove a dependency while dependent remains active. A selected-body cache and lifecycle/dependency authority therefore need distinct owners; no automatic refresh follows file mutation here.
