# Team composition rewards additional failure labels and lacks aggregate budgets

**Historical finding; current closure not revalidated.**

After primary selection, compose_team adds a candidate when its known_failure_modes are not a subset of the accumulated failures. This grows failure-label coverage, not proven complementary success. Duplicate IDs resolve back to first matching profile. max_agents zero or negative can still select the first candidate because limit checks follow append. Each profile passes individual budgets only; team aggregate cost/risk is not evaluated and no agents run.
