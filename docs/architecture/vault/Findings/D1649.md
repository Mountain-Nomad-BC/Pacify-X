# Startup zero-effect counters are declarations rather than measurements

**Historical finding; current closure not revalidated.**

startup records elapsed activation time but subprocesses_started=0, discovery_started=false and project_writes=0 are hardcoded. Canonical memory lease start and listener/provider registration precede this assignment; imported owners determine actual deferred behavior. These constants are not independently observed effect counts.
