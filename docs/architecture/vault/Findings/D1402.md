# Reservoir replacement changes stability requirements for specialized sorts

**Historical finding; current closure not revalidated.**

Reference comparison sorts use original source ordinal as tiebreaker. Reservoir replacement does not keep the sample in ordinal order. Counting and radix preserve sample order within equal keys, and all-equal bucket sort returns sample unchanged, so those candidates can fail the declared reference after sampling despite ordinary stable behavior on their input order.
