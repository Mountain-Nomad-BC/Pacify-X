# Resource valid and pressure counters have separate meanings

**Historical finding; current closure not revalidated.**

resource_status returns valid true regardless of active resources or cleanup failures. storage_status valid depends on optional stored-counter alerts; critical disk pressure alone does not make it false. Owned bytes/files come from ledger counters, not a fresh inventory; workspace count includes all unreclaimed ephemeral resource types.
