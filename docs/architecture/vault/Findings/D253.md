# Scanner language coverage and retained text vary across adapters

**Historical finding; current closure not revalidated.**

Python AST records include nested scope approximations; JS/other-language regex can match comments/strings and captures declaration-span rather than full function body. C/C++/Swift are classified source but have no symbol scanner here. Compose parser falls back on any exception without a dedicated parse-warning signal. Origin URLs/config key values are constrained, but Docker entrypoint text, Compose image/build/ports and headings are retained and are not universally content-redacted.
