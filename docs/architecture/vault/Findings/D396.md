# Logic exceptions are monotonic firing guards rather than truth maintenance

**Historical finding; current closure not revalidated.**

Rules execute in descending priority and ID order; once support is added it is not retracted if an exception is derived later. Reordering rules can therefore change retained conclusions. Rule IDs need not be unique and derivation support uses only rule:id. Literals are ground exact tuples, without variable unification or unrestricted theorem proving.
