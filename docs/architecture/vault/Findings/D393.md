# Formula evaluation always computes perturbations and has distinct numeric limits

**Historical finding; current closure not revalidated.**

FormulaEngine accepts float-coercible finite values, including booleans/strings, and has no input magnitude cap; bare Name return bypasses intermediate-result bounds. It computes sensitivities even without requested uncertainty. Declared bounds guide perturbation, but implicit sqrt/log/division domains can still fail at an otherwise evaluable point. This differs from the foundry interpreter contract.
