# Source audit progress replacement is atomic per file but not a durable transaction

**Historical finding; current closure not revalidated.**

Progress uses a deterministic .tmp path and os.replace without exclusive creation, fsync, lock or finally cleanup. Final report writes directly. Stat/hash/metadata reads are not an immutable snapshot. CLI allow-errors can exit zero while complete remains false, and printed excluded count uses a key not populated by the coverage counters.
