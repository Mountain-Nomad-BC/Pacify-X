# Foundry lineage signature is an unkeyed integrity digest

**Historical finding; current closure not revalidated.**

lineage_signature is SHA256 of a public domain prefix plus candidate hash; signed_by is a fixed string. Validation recomputes the digest but authenticates no external signer. This supports content consistency, while source hashes/citations and candidate-only authority remain separate claims. Export filters missing source references rather than requiring complete reference membership.
