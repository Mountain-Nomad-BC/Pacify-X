# Installed declared-file availability intentionally accepts omitted source assets

**Historical finding; current closure not revalidated.**

resolve_declared_path returns None for extension/tests/scripts in non-source layout and declared_file_available treats None as available. Runtime/builders redirect to installed module locations. Tests explicitly require the exemption. Consumers must not interpret this result as proof the referenced file shipped; navigation adapters that directly root-join paths have different behavior.
