# Terminal severity precedence is source-driven

**Historical finding; current closure not revalidated.**

Blocking process/page/console wins failed, source_identity/extension_host wins blocked, other blocking sources yield incomplete. Severity error itself does not force failed; profile errors become incomplete. Exit codes map completed/failed/incomplete/blocked to 0/1/2/3, so consumers must preserve both scope and issue provenance.
