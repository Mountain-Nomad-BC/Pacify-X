# Workflow approval can be attached to a different current session

**Historical finding; current closure not revalidated.**

The pending approval records workflow ID/version, but response matching compares only requestId, nodeId and nonempty approval_id. Later code assigns to any current workflow studioSession. An unchanged listener in a VM accepts approval for workflow A and writes it into current workflow B. This is transient UI contamination; backend approval capabilities remain separately authoritative.
