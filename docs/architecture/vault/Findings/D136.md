# Memory materialization does not supply current revision freshness checks

**Historical finding; current closure not revalidated.**

validate_memory_query_plan can compare current source/dependency revisions when explicitly passed. materialize_memory_context calls it without those arguments, and agent preview passes only plan, supplied records and clock. Therefore the shown path checks plan integrity but does not establish that its retained source/dependency revision values are current.
