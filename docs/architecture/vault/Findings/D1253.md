# Aggregate splitter rejects new children before creating them

**Historical finding; current closure not revalidated.**

_parent_child_set always includes new_children IDs. main computes unknown=set(children)-set(cards) and exits before the later loop that would append missing card_discovered events. Therefore new_child_cards cannot become nonzero through this path; script presently reconciles only already-existing allocated IDs.
