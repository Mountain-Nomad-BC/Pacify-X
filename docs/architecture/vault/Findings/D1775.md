# Receipt publication precedes owned browser closure and is not atomic

**Historical finding; current closure not revalidated.**

Main overwrites the final receipt before viewport detach/browser.close, so closure failure can leave a completed-looking artifact with process exit1. Early failure may leave an older receipt in place. Progress appends to a preexisting path without a new exclusive run envelope. No final cleanup receipt binds released frame/listener ownership.
