# Cancellation with valid numeric request ID zero is ignored

**Historical finding; current closure not revalidated.**

The wire RequestIdSchema accepts integer IDs, but Protocol._oncancel returns on falsy requestId. The extracted-method pure report probe shows ID0 yields no abort while1 and a string abort their fake controllers. This is a bundled dependency behavior, not a whole SDK operational test.
