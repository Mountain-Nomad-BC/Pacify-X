# Host context cache does not carry a workspace key

**Historical finding; current closure not revalidated.**

Five-minute hostContextCache and governor key host-context are shared inside activation. Current environment is also reused through currentEnvironment || readEnvironmentInventory(root). Configuration/extension events clear context, but there is no workspace-folder-change handler in this file. A changed first workspace can reuse context/environment until another invalidation.
