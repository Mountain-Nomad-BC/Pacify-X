# I/O paths require one matching type rather than all capability prerequisites

**Historical finding; current closure not revalidated.**

find_io_paths advances when current type appears in consumes and adds each provided type. Other consumed types, dependencies, conflicts, authority and lifecycle readiness are not required. It limits returned paths but can explore a large frontier; rank_io_paths only evaluates first 4*limit candidates, so metadata ranking is not a global optimum.
