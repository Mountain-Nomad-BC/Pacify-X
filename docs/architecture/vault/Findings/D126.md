# Memory append has several publication points before its returned receipt

**Historical finding; current closure not revalidated.**

Lifecycle event, anchor and head are published before record JSON and Markdown note. No transaction wraps all these files, and records/lifecycle readers do not take the writer lock. A failure or concurrent read can observe intermediate state; underlying FileLock serializes writers only.
