# Extension scan bounds do not bound candidate hashing time

**Historical finding; current closure not revalidated.**

maxDirectories/maxCandidates use Number(options.value || default), so nonfinite/nonnumeric truthy values can disable comparisons for direct callers. Each candidate permits50000 entries but has no byte/time bound; a large readdir is allocated before counting. Cancellation is checked between discovery entries, not inside inventoryDirectory/hashFileStable. Candidate failures are silently dropped without an unresolved list.
