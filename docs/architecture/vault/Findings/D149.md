# Handoff consumed view omits hypotheses and open questions

**Historical finding; current closure not revalidated.**

Packet creation retains hypotheses and open_questions, but consume_handoff returns evidence, authority, budgets and identity without those two fields. Agent governed preview subsequently returns only packet hashes. Transferring these reasoning contents requires an additional consumer path; presence in a persisted packet is not proof the receiving executor sees them.
