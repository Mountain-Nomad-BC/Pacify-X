# Opening cached context does not force a fresh read

**Historical finding; current closure not revalidated.**

openContextSnapshot uses currentContextEnvelope when present. continueWithCodex sets the objective-bearing envelope, opens it, then publishSnapshot(false) can replace global context with cached host-context envelope. The displayed document and later global context can differ; cancellation clears only local context, not an external Codex session.
