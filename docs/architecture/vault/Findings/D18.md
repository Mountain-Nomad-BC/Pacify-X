# Observed-effects fields have different evidence strength

**Historical finding; current closure not revalidated.**

RuntimeLifecycle.run_verified_tool copies declared_effects into observed_effects after a successful callback. That receipt records wrapper-level attribution, not independent OS measurement. Separate operational observers exist. A graph reader must follow the producing path before using an observation field as proof of the actual effect.
