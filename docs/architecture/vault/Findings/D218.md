# Decoded model validation omits constructor path and revision checks

**Historical finding; current closure not revalidated.**

Builder contains resolved local path, requires .gguf and validates fallback revision strings. validate_model_attachment hashes root/path without the same containment/suffix checks, does not validate fallback revisions, and does not enforce schema_version. A self-consistent decoded attachment can therefore satisfy different conditions than one built through constructor.
