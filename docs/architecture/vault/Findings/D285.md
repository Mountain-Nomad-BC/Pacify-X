# Projection rebuild compensation is narrower than atomic publication

**Historical finding; current closure not revalidated.**

Rebuild replaces registry, seal and sessions sequentially and restores only targets that existed before call. Unexpected session files remain; newly created session targets are not removed on rollback. Final committed record, recovered-intent events and dashboard follow the compensating block. The atomic-named test verifies bytes after caught exception, not reader isolation or process-kill recovery.
