# Agent structural admission and launch readiness are different gates

**Historical finding; current closure not revalidated.**

test_candidate labels its receipt structural_preflight_not_behavioral_certification and excludes memory_runtime_resolved/handoff_runtime_resolved from admission_ready. _new_session later calls plain preview, which blocks unresolved memory/handoff bindings. Governed preview accepts additional broker/handoff inputs through a different API. A passed preflight or admitted catalog row therefore does not imply an ordinary launch can run.
