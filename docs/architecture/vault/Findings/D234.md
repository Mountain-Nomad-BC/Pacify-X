# Registry graph publication and source hashing are separate phases

**Historical finding; current closure not revalidated.**

Graph builders read source metadata, construct output bytes, then reread source paths for manifest hashes. Concurrent source changes can bind output to later source bytes. Writer publishes six files sequentially without a shared reader/writer lock or atomic directory swap; validator later detects stale or extra files by rebuilding. Declared executes stage edges do not prove an invocation.
