# Read-only enterprise MCP routes can persist state without the write gate

**Historical finding; current closure not revalidated.**

pacify_enterprise_status and pacify_billable_guardrail_evaluate are read-only annotated but call initializeEnterprise with default persistence. Missing or migrated state causes a write. Middleware authorizes only non-read-only annotations and derives both declared and observed effects from the label. Dashboard callers pass persist false. Existing tests separately check nonpersisting initialization and tool labels but do not cover this composition. This is source-derived, not a fresh execution finding.
