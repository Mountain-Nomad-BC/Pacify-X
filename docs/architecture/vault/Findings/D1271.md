# Unobserved foreign rows can pad receipt cardinality before membership checks

**Historical finding; current closure not revalidated.**

Receipt total, record length and globally unique IDs must equal known control count. A record yielding no observation is skipped before known surface/control membership checks, so cardinality alone does not guarantee exact receipt membership. Full completion additionally requires every expected observation, limiting the effect on final valid status.
