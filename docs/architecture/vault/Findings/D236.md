# Service golden validity can disagree with routing validity

**Historical finding; current closure not revalidated.**

evaluate_service_golden_queries tests only missing must_include and present must_exclude IDs. It ignores routed valid and denials; a case may satisfy ID expectations while its route is refused. Empty case set also produces valid true. Production tests require configured twenty cases but evaluator does not enforce that denominator itself.
