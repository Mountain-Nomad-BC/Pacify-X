# Activation transaction cannot own values before argument evaluation finishes

**Historical finding; current closure not revalidated.**

Output channel/publisher/catalog are created before their first transaction.own call. Multiple registrations are passed as function arguments to one own call; if a later argument throws, earlier-created disposables from that expression may not yet be registered with transaction. Explicit rollback helps only resources already enrolled.
