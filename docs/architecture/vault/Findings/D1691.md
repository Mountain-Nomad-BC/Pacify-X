# Prior walker profile failures are lost during child recomputation

**Historical finding; current closure not revalidated.**

The walker passes profileFailures as additionalIssues into its first status evaluation and stores status_truth. The isolated child reads that receipt but calls evaluateOperationalWalk again with only normalized processIssues. The evaluator ignores prior status_truth. It accepts expected nonzero exit derived from the original status. A pure reproduction changes original incomplete with a retained profile failure to completed.
