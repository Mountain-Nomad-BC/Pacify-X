# Persistence guarantees belong to specific publication units

**Historical finding; current closure not revalidated.**

Coordination withState publishes deferred files, state, event, receipt and handoff in order. The protected Python ledger publishes event bytes before its head; validation detects head/chain disagreement. Studio directory publication uses a no-replace atomic primitive. These are different guarantees: neither a file lock nor a hash chain makes every related file a single atomic transaction. This is source reasoning about interruption boundaries, not a reproduced crash result.
