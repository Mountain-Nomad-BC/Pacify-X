# Behavior extraction reads broad mutable source trees without size bounds

**Historical finding; current closure not revalidated.**

It enumerates all is_file paths with rglob and no exclusion policy or error denominator, follows file links, hashes then stats then reads entire text separately. Large files and full record lists are unbounded. Missing/unreadable hash paths abort rather than entering parse_failure_count; changing files can break hash-to-metadata identity.
