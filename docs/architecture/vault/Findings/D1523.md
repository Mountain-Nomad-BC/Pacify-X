# Sanitizer text classification and binary coverage differ

**Historical finding; current closure not revalidated.**

The first64KiB NUL check decides binary versus UTF-8 treatment. A NUL-free binary with invalid UTF-8 raises preservation preflight failure under apply; later text errors are recorded. Binary scanning checks configured identifier patterns in Latin-1 chunks but does not rewrite binary content. Root names themselves are outside the rglob rename list.
