# Declared wrapper is a projected executable template

**Historical finding; current closure not revalidated.**

Installed imports take precedence and any ModuleNotFoundError triggers fallback imports after inserting parents[4]. Argument parsing executes at module import. Input JSON is read without a byte bound and malformed shape/owner exceptions are uncaught. The directory-depth assumption belongs to projected wrappers, not arbitrary direct template execution.
