# Stale-group resource closure is scoped to newly unresolved identities

**Historical finding; current closure not revalidated.**

Baseline unresolved ephemeral IDs are excluded from the final new-resource check. Late current/parent PIDs and exact release-owner run/lane identities are also exempted. Reconciliation can return globally invalid while refresh succeeds when only prior/exempt resources remain. This is a scoped closure predicate, not a claim that the entire resource ledger is clean.
