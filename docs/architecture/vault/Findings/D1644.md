# Enablement observation explicitly records temporal association only

**Historical finding; current closure not revalidated.**

A single pending handoff with five-minute expiry is consumed by next extension-change event, then refreshed only if a view is visible. The emitted receipt says temporal-pending-handoff-only, enablement_observed=null and activation_is_not_enablement=true. Multiple concurrent handoffs overwrite this single slot; arbitrary extension change can consume it.
