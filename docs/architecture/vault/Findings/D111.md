# Authenticated catalog status is not rebound to the JS record read

**Historical finding; current closure not revalidated.**

Python verifies lifecycle receipts against current record/tree bytes internally, then emits a row keyed by relative path with status/authenticated/reason but no record digest. PxBridge fetches that projection before studioCatalog reads physical records, and can reuse the status response cache. JS uses authenticated === true to choose displayed status without comparing the projection to its new revision digest. This is an observation-time gap; it does not prove the separate mutation authority accepts changed source.
