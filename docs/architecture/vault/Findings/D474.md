# Evidence cache reserved revisions can be shadowed by dependency names

**Historical finding; current closure not revalidated.**

EvidenceCache.key constructs source/authority/toolchain fields then expands caller dependency_revisions into the same mapping. A dependency named source_revision can replace the explicit source revision, yielding a key that does not bind that argument. Stringified dependency keys can collide too. Values require SHA format, not authoritative freshness or complete dependency inventory.
