# Evidence cache immutability applies to blobs rather than key mappings

**Historical finding; current closure not revalidated.**

put stores content-addressed blobs but overwrites entries[key], so same revision key can point to a different result. Corrupt/missing manifest often resets to empty, while some malformed shapes/Unicode errors escape. get builds a path from unvalidated manifest digest before integrity checking and locks even reads; no blob size cap exists. Prepared files use atomic replace without fsync or failure cleanup, and blob publication can precede failed manifest write.
