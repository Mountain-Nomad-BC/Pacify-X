# Refinery portable inventory separates walk snapshot from later byte reads

**Historical finding; current closure not revalidated.**

bounded_walk captures file metadata and applies traversal limits; portable_inventory later reads entire files for hashing and rereads small files for secret scanning without a retained snapshot identity. Files over max_text_bytes are not scanned for secrets, yet valid means no detected findings. Digest and scan can observe different contents; size counters retain walk metadata.
