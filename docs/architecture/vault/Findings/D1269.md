# Observation fallback and ledger normalization have different semantics

**Historical finding; current closure not revalidated.**

A visible clean complete indicator can enter fallback whether observed is omitted or explicitly false. The produced v1 observation can retain observed=false, while ledger v1 normalization derives observed from rendered and drops extra fields. Conversely a nonvisible observed=true/rendered=false planner result may fail ledger operational admission.
