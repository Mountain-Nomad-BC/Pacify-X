# Action inventory duplicate rows can collapse before count validation

**Historical finding; current closure not revalidated.**

Action records are keyed by action name and compared only with declared action_count. Duplicate rows can be hidden if the declared count matches unique keys. Navigation parsing uses regex over two specific const-array forms, so source formatting or commented text can affect discovery independently of runtime rendering.
