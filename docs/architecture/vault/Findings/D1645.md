# Studio create origin trust has explicit bounds and detach semantics

**Historical finding; current closure not revalidated.**

Active create map rejects duplicate kind/request and more than 64 operations. Host-origin proof ownership, initial physical absence, source reauthentication and postcommit warning handling are delegated explicitly. Closing panel disposes origin trust and marks create operations detached; it does not cancel already committed or running work.
