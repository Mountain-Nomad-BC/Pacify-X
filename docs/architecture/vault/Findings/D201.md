# Custody builder binds subjects after taking archive bytes

**Historical finding; current closure not revalidated.**

Build reads each source into ZIP, writes chunks, then rereads certificate and subjects to calculate bindings. No source snapshot equality spans those observations. A changing source can yield a binding that differs from its archived bytes; publication subject checks can reject that later. chunk_size is not required positive, with zero yielding no chunks and negative reading all.
