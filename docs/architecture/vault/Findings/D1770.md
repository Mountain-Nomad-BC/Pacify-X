# Owned-host flags do not themselves prove exact host authority

**Historical finding; current closure not revalidated.**

Child authority derives from PX_OWNED_VSCODE_HOST and an argv token prefix plus effect flags. This is not marker/PID/birth/root custody and some prefix checks admit an empty token. The parent and individual helpers have additional checks; their proof cannot be inferred solely from these booleans.
