# Declarative parallel effect checks use inconsistent defaults

**Historical finding; current closure not revalidated.**

validate_orchestration checks requested effects using contract effects when step effects omitted, but serial_steps scan defaults omitted effects to empty. Conversely, any two explicitly serial-effect steps with max_agents greater than one are rejected without checking if depends_on serializes them, despite error text requiring a serial chain. Runtime scheduling is a separate owner.
