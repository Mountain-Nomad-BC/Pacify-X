# Calculation units establish dimensions without scale or offset conversion

**Historical finding; current closure not revalidated.**

Known units km/cm/mm all map to L, time variants to T, and kelvin/absolute Celsius/delta Celsius to Theta. Values are never converted before arithmetic. Dimension compatibility alone can accept mixed scales or physically invalid absolute-temperature operations. Unit parser also tolerates repeated/trailing operators rather than a strict unit grammar.
