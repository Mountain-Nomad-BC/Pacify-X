# Deduplicated archive tree hash binds metadata rather than member contents

**Historical finding; current closure not revalidated.**

Simple catalog entry trees use path hash, uncompressed/compressed sizes and CRC, sorted by path hash. It does not read payloads or reject duplicate entry paths/hazards. Identical archive bytes share stored maps, but every occurrence is still parsed. Invalid ZIP occurrences remain and CLI still exits successfully.
