# Graph rendered acknowledgement does not prove paint completion

**Historical finding; current closure not revalidated.**

reportGraphRender counts DOM elements and calculates node rectangles from model positions. Visible count prefers non-virtualized frames, including forced selected frames. The 250ms fallback prepares geometry and reports without awaiting frame chunks; a suspended renderer can therefore report before virtualization finishes. Host stores supplied counts as rendered without independent request correlation.
