# Host model cancellation is cooperative rather than an enforced race

**Historical finding; current closure not revalidated.**

The deadline cancels a token and wall time is checked between rounds. Awaited host token-count/request/invoke calls and stream iteration are not raced against a rejecting timeout. Cancellation requested before listener registration is not explicitly inspected at that point. The host API must honor the linked token for timely completion.
