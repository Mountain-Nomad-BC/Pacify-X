# Canonical memory normalization can precede reliable predecessor capture

**Historical finding; current closure not revalidated.**

Attached state is disconnected before its previous root is fully validated. On failure, an already attached state may be marked restored without comparing root; failure before baseline capture leaves a false detached default and may disconnect a preexisting attachment. Restoration checks selected UI/target fields rather than exact registry state.
