# PX does not retain the serving handle or integrate application shutdown

**Historical finding; current closure not revalidated.**

The final serveStdio call discards its close handle and supplies only onerror. Stdio transport attaches data/error callbacks, not stdin end/close callbacks in this implementation. No source-level application hook reconciles PX effects on EOF/signal here; generic SDK closure only aborts cooperative handlers.
