# Listener coverage can mean registered rather than exercised

**Historical finding; current closure not revalidated.**

markRegistered can mark an available enabled listener healthy with events_recorded still zero. snapshot excludes unsupported required APIs from incomplete and can report coverage_complete when the bus is connected. buildActivityAttestation copies the same supplied effect label into declared and observed. Read this as supported listener registration/publication coverage, with explicit limitations, rather than independent observation of every actual effect.
