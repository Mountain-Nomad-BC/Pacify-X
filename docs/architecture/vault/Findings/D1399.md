# Sort JSON streaming does not preserve JSON token boundaries

**Historical finding; current closure not revalidated.**

Confirmed using in-memory readers: [12345] at chunk size two yields three records [1,23,45]. raw_decode accepts a numeric prefix before the next chunk arrives. The parser also accepts missing/repeated/leading/trailing commas and ignores text after the closing bracket; [,1 2,,,] ignored yields [1,2].
