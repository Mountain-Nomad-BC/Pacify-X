# Built-artifact checker does not invoke intrinsic manifest validation

**Historical finding; current closure not revalidated.**

verify_built_artifact trusts supplied record/allowed-generated mappings, checks required only when exactly True and compares hashes for present records. It ignores manifest.valid and source sizes. bind_artifact_set adds intrinsic validation when manifest supplied; direct verifier is weaker.
