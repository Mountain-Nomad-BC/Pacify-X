# Native input server authenticates PID birth before foreground recovery

**Historical finding; current closure not revalidated.**

Requests require secret equality, sequence above in-memory last value, exact root PID, allowed key/action and current ten-second-max interval. Each accepted request compares root process creation time. Ancestry walk is bounded to 128 parents; visible owned windows are preferred, hidden owned windows can be restored, and disabled modal owners are not excluded.
