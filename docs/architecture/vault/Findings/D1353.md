# Text repair ordering permits cascades and empty search strings

**Historical finding; current closure not revalidated.**

Mappings sort by descending search length then lexical key and apply sequentially. Replacement text may be changed by a later mapping, and empty search keys insert text between characters. JSON repair changes values only and always reserializes, so changed can be true with no replacements while object keys stay unchanged.
