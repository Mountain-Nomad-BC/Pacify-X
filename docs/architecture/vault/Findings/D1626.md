# External host run cancellation is classified differently from progress cancellation

**Historical finding; current closure not revalidated.**

Progress UI cancellation sets hostCancelled=true and cancels token; pause/cancel/stop routes first call backend then cancel activeHostRuns token without setting that local boolean. A resulting thrown model error can be labelled failed by this helper rather than cancelled. Backend run-state reconciliation may impose the final state separately.
