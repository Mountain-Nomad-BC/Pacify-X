# Focused completion is promoted in the nested launcher flag

**Historical finding; current closure not revalidated.**

A successful focused walk correctly returns operationally_complete=false and scope_complete=true. Launcher recomputation returns operationally_complete=true whenever no issues remain, losing that distinction. The outer report separately sets full_operational_completion_claimed=false for focused profiles, leaving conflicting nested scopes for consumers to interpret.
