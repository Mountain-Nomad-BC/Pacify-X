# Change proof classification is lexical metadata and has precedence traps

**Historical finding; current closure not revalidated.**

Paths are stripped and slash-normalized without resolving dot segments or verifying a diff. Marker substrings such as version can raise unrelated files to release critical. Authority/schema paths return before declared effects, so effects do not always produce the higher RUNTIME class. Malformed non-list symbols/effects are silently treated empty. Upward override verifies hash shape and nonempty approver/rationale but does not retrieve evidence.
