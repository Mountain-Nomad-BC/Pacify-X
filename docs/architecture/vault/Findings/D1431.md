# Catalog text matching is narrower than TOML identity

**Historical finding; current closure not revalidated.**

The migration detects existing IDs only with an exact double-quoted id = line regex. Equivalent TOML quoting/spacing can be missed and append duplicates; an existing matched entry is not updated for status/body/version changes. Catalog is rewritten even if no new entry was added.
