# Expired stored claims are rejected before built-in expiry cleanup

**Historical finding; current closure not revalidated.**

withState copies state and calls assertCoordinationState(previous, requireSeal false) before expireClaims. That validator still invokes conformance, which rejects active claims whose expires_utc is at or before now. Thus an otherwise intact stored active lease that has expired prevents the normal mutation path from reaching expiry normalization or its mutator. Read paths expire only in-memory projections. This is a source-derived ordering boundary; no clock-controlled reproduction was run.
