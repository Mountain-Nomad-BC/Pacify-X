# Resolver integrity does not impose a complete evidence record schema

**Historical finding; current closure not revalidated.**

Resolver parses unbounded JSON and accesses mapping methods without a root mapping guard; malformed roots can raise outside selected catches. It does not compare evidence_id with reference filename or require a full record schema. Signer trust and caller producer allowlist are checked separately without a signer-to-producer authorization mapping.
