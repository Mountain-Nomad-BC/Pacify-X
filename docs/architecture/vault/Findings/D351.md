# Generated equality gate can accept a matching invalid graph report

**Historical finding; current closure not revalidated.**

validate_generated_artifacts marks its generated dependency check valid when stored JSON equals computed report, without requiring report.valid. A stored two-node-cycle report can therefore match an invalid expected result at this check. Release preflight separately evaluates the helper valid flag; these gates should not be conflated. Installed profile comparison can also be vacuously true when owner glob is empty.
