# Registry and repeated session reads do not share one pinned snapshot

**Historical finding; current closure not revalidated.**

Config reader compares original bytes and seal again, but registry reader parses bytes then separately hashes path and compares seal. Session active-set path validates full event history, then calls _verified_session for each session which validates full history again. A short status result can therefore perform repeated whole-history reads and combine separate observation times.
