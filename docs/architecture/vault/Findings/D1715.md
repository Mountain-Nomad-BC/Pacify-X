# Natural walker exit is recorded as termination verification

**Historical finding; current closure not revalidated.**

After waitForExit the child sets walker_termination_verified=true without descendant verification in that branch. Helper natural exit considers no signal termination verified even when nonzero; it adds separate failure string later, which normalizer drops. Full parent process-tree proof is a different owner and must not be conflated.
