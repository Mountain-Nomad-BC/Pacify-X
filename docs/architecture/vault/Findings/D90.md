# Native patch scope omits deleted-file destinations

**Historical finding; current closure not revalidated.**

patch-scope-guard adds paths only from +++ b/ headers. A deleted-file header uses +++ /dev/null, so the removed path is absent from denied-file checks; its removed text still contributes to the line count. Empty allowed patterns disable path filtering. The helper reports a decision and does not intercept another executor applying a patch.
