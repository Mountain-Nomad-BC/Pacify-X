# Automatic recovery distinguishes malformed suffix from semantic corruption

**Historical finding; current closure not revalidated.**

Recovery only considers non-newline-terminated final suffix within event bound and first validates complete prefix. Invalid UTF8/JSON suffix is retained as exact base64/hash receipt before truncation. Syntactically complete but semantically invalid event is preserved and rejected. Valid complete event missing delimiter gets receipt then newline. No recovery executed by this audit.
