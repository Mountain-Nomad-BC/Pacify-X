# Contract corpus fixtures are narrow checks with shared implementation

**Historical finding; current closure not revalidated.**

Corpus generates a minimal positive and checks it using the same interpreter, plus empty-object negative only where required fields exist. Ownership records keyed by path overwrite duplicates and referenced producer/test lists need not be nonempty. build_minimal_instance itself returns an unvalidated candidate; integer fixture generation casts multipleOf to int, so an admitted positive fraction can become zero. These are source-observed limits, not a fresh conformance test.
