# Native Python test portability is constrained before skip checks

**Historical finding; current closure not revalidated.**

The helper imports WinDLL and WINFUNCTYPE at module import, while the test imports the module before its Windows-only test decorator. On platforms lacking these ctypes names, collection fails before the skip. ABI checks alone do not prove foreground or SendInput effects.
