# Exact duplicate groups trust supplied hashes and can contain only one distinct ID

**Historical finding; current closure not revalidated.**

Grouping uses declared sha256 and int(bytes), without reading source contents. It requires two input rows before deduplicating IDs, so repeated same-ID rows can emit a count-one group. Group IDs truncate SHA and omit size, though grouping key includes size.
