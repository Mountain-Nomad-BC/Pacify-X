# Host action durable naming describes in-memory retention

**Historical finding; current closure not revalidated.**

Host result waiters consult current response arrays, controller globals and latest snapshot, matched by request/operation and a lower time bound. Extension state is in memory, not a persisted journal; tests explicitly forbid globalState retention. This can support webview reconstruction while not proving extension-process restart durability.
