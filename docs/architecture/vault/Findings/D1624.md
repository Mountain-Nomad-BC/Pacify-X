# Prepared host run can outlive initial webview failure

**Historical finding; current closure not revalidated.**

The backend prepares a durable run before the running result is posted. That post occurs before creating activeHostRuns cancellation state and before the try wrapping model execution. A disposed/erroring webview can leave the prepared run without executing/completing it through this local branch; external reconciliation remains necessary.
