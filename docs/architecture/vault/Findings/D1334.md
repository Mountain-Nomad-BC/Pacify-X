# Source comparison misses normalized matches of different byte lengths

**Historical finding; current closure not revalidated.**

Workspace candidates are prefiltered by source raw byte sizes before both exact and normalized comparison. Whitespace-only changes that alter length can therefore be absent from normalized matches. Normalization casefolds code/text and collapses whitespace, which is not semantic equivalence.
