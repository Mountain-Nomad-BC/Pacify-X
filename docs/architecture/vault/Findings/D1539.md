# Extension candidate IDs are selectors rather than authorization tokens

**Historical finding; current closure not revalidated.**

IDs are truncated root/path hashes and execution verifies basename/name/relativePath/classification/retention plus inventory. directoryIdentity is optional in executeCleanup, but the normal host retains its nonenumerable scan object and only sends display fields to the webview. The host passes its own candidates after modal approval, so a webview cannot directly substitute arbitrary candidate objects through that route.
