# Security operational schemas use local required-field definitions

**Historical finding; current closure not revalidated.**

Source YAML supplies contract name/purpose; local OPERATIONAL_CONTRACTS supplies actual required/properties and additionalProperties false. Constants such as approved, immutable, cleanup_verified or selected hashes valid describe accepted claims, not real authorization/evidence verification. Unknown names raise; missing source contract files are not independently counted here.
