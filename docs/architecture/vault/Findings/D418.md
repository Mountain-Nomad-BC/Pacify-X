# Black-box exclusive files lack sequence and path ownership controls

**Historical finding; current closure not revalidated.**

Recorder stores payload_hash, not raw nested payload. runtime_id, event_type and evidence_refs are stored verbatim. Sequence is count of root JSON files plus1 without a shared lock; different event types can concurrently share sequence. Unvalidated event_type becomes part of a path and parent directories are created; separator/dot-segment input can escape intended layout. Exclusive create prevents replacement of one exact path, not authenticated append-only history or containment.
