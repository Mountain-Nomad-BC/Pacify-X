# Owner-loss fixture does not demonstrate supervisor-death recovery

**Historical finding; current closure not revalidated.**

The liveness owner is os.getpid: the supervisor checks its own kernel handle/fingerprint while running. The owner-loss test mocks that fingerprint becoming unavailable and disables the handle; it does not kill the supervisor. Windows kill-on-close Job is a separate mechanism. POSIX polling alone cannot keep running after supervisor death.
