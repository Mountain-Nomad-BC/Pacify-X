# Full walk completion trusts the complete-chain aggregate

**Historical finding; current closure not revalidated.**

evaluateOperationalWalk checks control count/attempts and accepts complete_interaction_chains plus recovered boundaries at least equal to denominator. It does not recompute complete stages, inspect ordinary control errors, require rendered/visible, enforce unique IDs or cap inflated complete counts. Pure probe returns completed for one attempted control with empty stages and errors when aggregate says one complete.
