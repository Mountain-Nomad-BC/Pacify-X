# Generic instrumentation preserves caller identity and timestamps across lifecycle variants

**Historical finding; current closure not revalidated.**

SDK deep-copies payload and changes lifecycle/result only, retaining event_id, time and previous hash. A caller emitting variants directly to bus must refresh identity/linking itself; RuntimeLifecycle separately uses UUIDs. Started emission happens before try, failed emission can mask original exception, and completed-emission failure follows successful body execution. No effect observation or actor authorization occurs.
