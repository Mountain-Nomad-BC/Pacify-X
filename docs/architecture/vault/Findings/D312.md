# Worker reassignment and loss do not prove released physical ownership

**Historical finding; current closure not revalidated.**

Reassigning a worker can retain its old work ownership; multiple workers may reference one work. release removes assignments but leaves heartbeat entries used for agent counts. recover_lost releases the whole work and other assignments without stopping or verifying live workers. A timestamp threshold is not child-process closure.
