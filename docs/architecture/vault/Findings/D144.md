# Detached launch acceptance does not require a running live worker

**Historical finding; current closure not revalidated.**

launch_studio_worker returns accepted true and live_worker_observed true whenever durable state differs from launch_state, before checking process.poll. A failed/finalizing/cancel transition also satisfies this branch. The returned state must be interpreted directly; these booleans are not independent worker-liveness or successful-start proof.
