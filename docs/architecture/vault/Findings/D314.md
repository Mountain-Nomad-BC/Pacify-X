# Migration WAL does not pin the originally decoded source

**Historical finding; current closure not revalidated.**

migrate_state invokes WAL recovery before decoding source or rejecting a downgrade. Exact original bytes are backed up, but no owner lock or expected-source compare-and-swap spans decode through WAL commit; concurrent replacement can be overwritten. Unsupported target versions are rejected before WAL construction, which is a separate earlier check.
