# Service discovery heuristic uses whole-file keyword suppression

**Historical finding; current closure not revalidated.**

A selected config file warns only when an IPv4 address pattern appears and no discovery/resolver/TTL/registry keyword occurs anywhere. Unrelated comments can suppress a real stale-address concern; hostname-only or IPv6 paths are outside the detector. No service resolution or expiry is observed.
