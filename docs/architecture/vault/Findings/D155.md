# Resource reconciliation dry run can terminate owned processes

**Historical finding; current closure not revalidated.**

When a process record has an in-memory Popen handle, reconcile calls terminate_owned_process without checking apply. Thus apply=False can signal/terminate that process and publish state/receipt while the returned summary says dry_run true. Other cleanup dry-run branches also write receipts. The reviewed dry-run test covers failed path cleanup, not this process branch.
