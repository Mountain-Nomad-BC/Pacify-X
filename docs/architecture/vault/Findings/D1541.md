# Extension recycle fallback validates leaf but omits ancestor containment

**Historical finding; current closure not revalidated.**

Fallback forms .quarantine/cleanupId with lexical isInside checks, recursively creates it and verifies only that leaf is a plain directory. It does not call assertPlainDirectoryUnderRoot or compare realpath with rootGuard for this route. An existing linked .quarantine ancestor can redirect the destination outside the root. This is a conditional source finding; no symlink or move was executed.
