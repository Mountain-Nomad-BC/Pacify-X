# Ledger evidence-path handling has different bounds from report admission

**Historical finding; current closure not revalidated.**

Generic evidence resolution strips line suffixes and resolves contained paths before physical checks, so contained aliases can resolve to a physical target. _bind_evidence uses unbounded read_bytes; report manifest admission instead uses a 16MiB physical-file read and exact finding denominator/hash comparison.
