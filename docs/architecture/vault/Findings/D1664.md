# Graph virtualization hides eagerly created nodes

**Historical finding; current closure not revalidated.**

materializeGraphGeometry creates all node foreignObjects and minimap dots before frame processing. Virtualization chunks 280 frames and 420 edges per animation frame but does not defer DOM allocation. The selected node is forced visible even outside the viewport; an edge crossing the viewport can be hidden if both endpoint frames are hidden.
