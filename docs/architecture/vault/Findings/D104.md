# Existing environment shards are trusted by the writer and verified later by readers

**Historical finding; current closure not revalidated.**

writeDataset skips an existing target yet returns the digest of the newly serialized intended bytes. It does not verify or repair that target. A corrupted existing file can therefore survive refresh; later readDataset detects a mismatch and rejects it. Current index replacement and event append are separate, so event failure can leave a published current snapshot without its event.
