# Native dialog selection can escape exact dialog identity

**Historical finding; current closure not revalidated.**

Dialog discovery searches all context pages by text and may fall back to an actionable ancestor or body. Click resolution searches matching labels in dialog and workbench, selecting a visible candidate without uniqueness or exact request-to-dialog identity. Escape cancellation can report success without proving the expected modal was active.
