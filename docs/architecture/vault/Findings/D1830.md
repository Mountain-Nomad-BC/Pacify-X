# Domain result validity is not supplied by MCP input schemas

**Historical finding; current closure not revalidated.**

The SDK validates output only when outputSchema exists. PX registers strict input schemas but no output schemas, and wraps arbitrary values into structuredContent. A normal unavailable/failure object can be logged as completed/success by instrumentation because it did not throw. Wire result shape and domain success are different contracts.
