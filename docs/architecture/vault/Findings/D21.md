# Canonical persistence and graph success are deliberately separable

**Historical finding; current closure not revalidated.**

persist_with_graph_isolation writes the vault before invoking the graph callback. A failed derived write leaves canonical_persisted=True and requires reconciliation. StateKVGuard bounds the wait and opens a circuit on failures; canceling a Future does not demonstrate that a running callback has ceased effects.
