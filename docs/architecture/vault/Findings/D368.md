# Summary namespace sanitization retains dot segments and collisions

**Historical finding; current closure not revalidated.**

Session directory names replace unsupported characters but allow dots; a session ID of .. can resolve to the parent directory. Different IDs can normalize to the same name and share an unvalidated cursor. This is a direct helper boundary; source search found no production caller exposing it as an external route.
