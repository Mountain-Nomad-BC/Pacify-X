# Custom editor instruction hashing has its own Unicode boundary

**Historical finding; current closure not revalidated.**

Synchronous SHA-256 encoder expands code points manually but does not reject unpaired surrogate code units. Those encode differently from standard replacement-character UTF-8 behavior. Host exact trust serializer rejects unpaired surrogates; browser graph hash alone is not cross-runtime identity assurance.
