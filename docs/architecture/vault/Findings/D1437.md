# Contract ID normalization rewrites identifiers without reconciling consumers

**Historical finding; current closure not revalidated.**

All contracts/**/*.json are treated as schema objects. A changed ID requires $schema and otherwise raises after earlier writes; already matching ID skips that check. The path-derived URI is written directly, without updating absolute references, registries or provenance hashes or validating schema compatibility. Missing contracts directory returns zero changes.
