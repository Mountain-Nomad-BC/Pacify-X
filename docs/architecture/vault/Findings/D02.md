# The original bounded orchestrator has a narrower effect path

**Historical finding; current closure not revalidated.**

Orchestrator.run calls enforce without effect_grant_path, signature, trust policy or project/session bindings. enforce requires these for NON_READ_EFFECTS. Consequently this entrypoint cannot establish those non-read executions as written. Agent/Workflow Studio have separate authority paths; this does not mean all PX mutation is blocked.
