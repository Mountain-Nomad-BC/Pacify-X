# Research independence is citation-string diversity

**Historical finding; current closure not revalidated.**

canonicalize_research counts distinct casefolded citation strings, not distinct verified publications, authors or evidence hashes. It checks source SHA length but not hexadecimal content. The positive test assigns identical source hash to two citation strings and receives multi_source. Bundle hash follows input order even though groups are sorted.
