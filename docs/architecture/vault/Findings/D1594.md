# Native approval keys are not bound to dialog semantics

**Historical finding; current closure not revalidated.**

Cancel alone maps to Escape; any other label approves via Enter with zero/one/two Tab traversals. Correlation strings are retained but neither server nor client verifies the targeted modal label, control action or operation payload at send time. Process ownership constrains host, not intended UI decision.
