# Finalizer and Agent runtime use different run-receipt locations

**Historical finding; current closure not revalidated.**

Agent _execute_session writes the signed receipt to record_path.parent/runs/run_id.json, below its immutable revision. finalize_studio_run_if_worker_exited checks state_root/runs/run_id.json and updates it only if present. The detached session wrapper does not copy the Agent receipt there. Therefore terminal durable state can be updated while the existing revision receipt remains finalizing.
