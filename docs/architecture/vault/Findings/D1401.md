# Sort coercion and type policy distinguish compatible numeric shapes

**Historical finding; current closure not revalidated.**

Every key must have exactly the same Python type, so int/float mixtures fail even when numerically ordered. String coercion applies only to strings; number policy leaves existing integers unchanged. Boolean keys are allowed only as a homogeneous class. Auto coercion can retain non-finite-looking strings as text after numeric conversion fails.
