# Physical bounded reads do not establish an immutable content snapshot

**Historical finding; current closure not revalidated.**

read_bounded_regular_file opens once, checks descriptor regular type/size and reads size+1 at most, rejecting length change. This bounds retained bytes and catches growth/shrink but does not detect a same-size concurrent modification. Root containment and ancestor checks are outside this helper; O_NOFOLLOW is used only where provided.
