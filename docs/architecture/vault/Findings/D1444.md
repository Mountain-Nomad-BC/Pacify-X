# Processing project mutation can use a different orchestration lock root

**Historical finding; current closure not revalidated.**

Confirmed in isolated main: the orchestration lock receives framework root, while processing-order --project claim-release-stage passes the selected project root to the release owner. This does not remove the release owner own state checks/locks, but the repository-wide orchestration exclusion is not scoped to that mutated project.
