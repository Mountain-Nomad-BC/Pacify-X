# Delta checkpoint preflight and retention have separate limits

**Historical finding; current closure not revalidated.**

Preappend preflight builds ordinary head. Delta-specific head fields are added and bounded after authoritative append. Cumulative delta is content-addressed; existing path is reused without reading equality in writer, though reader later verifies it. Old cumulative deltas are not reclaimed here, and compaction occurs only when delta bytes exceed 16MiB.
