# Extension cache custody differs from canonical repository custody

**Historical finding; current closure not revalidated.**

The JS scanner skips .git/node_modules and root evidence/quarantine trees, but has no canonical exclusions for virtual environments, Python installations or preserved-skills trees. Any recognized cache basename can receive safe-to-delete and retentionRequired=false after structural inventory. Name classification does not establish content ownership or retention. Host requires explicit selection and modal approval, which remains a separate boundary.
