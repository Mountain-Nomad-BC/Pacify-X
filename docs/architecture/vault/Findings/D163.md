# Unexpected supervision callback failure skips normal terminal publication

**Historical finding; current closure not revalidated.**

The main finally closes Job/liveness handles and joins capture threads, but does not itself call POSIX shutdown. An exception from cancellation polling, disk accounting or another loop operation can propagate before resource closure and receipt creation. Post-spawn identity update and thread startup also precede this try. Thread join timeout is not followed by an alive check.
