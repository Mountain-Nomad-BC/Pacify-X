# Sanitation composition does not propagate identifier top-level errors

**Historical finding; current closure not revalidated.**

build_sanitation_summary copies only identifier_audit.gates, replaces the five not-run controls and derives validity from gate statuses. It does not carry identifier_audit.errors or scoped_valid. A transient identifier-only read failure can therefore be lost if other scans pass and base gate hit lists are empty. Release/export callers use this compositor result; this is a source-derived failure path, not an executed release.
