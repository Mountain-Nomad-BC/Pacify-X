# Workspace event and projection publication can diverge on failure

**Historical finding; current closure not revalidated.**

Session creation/renewal/release event precedes projection replacement; admission and lifecycle registry replacement precede their event. Registry and seal also replace separately. Readers do not share mutation lock and may see mismatch. Decorators detect changed config after function returns, with no rollback of completed effects; the test checks the raised error only.
