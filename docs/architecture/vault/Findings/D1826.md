# Inbound request concurrency is not bounded by the raw stdio buffer

**Historical finding; current closure not revalidated.**

ReadBuffer limits raw accumulated bytes to10MiB. Decoded messages enter an unbounded queue, and _onrequest schedules handler promises without a configured global in-flight bound. Async callbacks can overlap and parsed request memory can outlive the byte buffer. Synchronous PX handlers add event-loop blocking instead of cooperative admission.
