# Hash-backed inventory accounting excludes traversal failures and configured omissions

**Historical finding; current closure not revalidated.**

Selected file failures are retained and cause CLI failure, but os.walk has no onerror and pruned directories/root-files-only entries never enter files_discovered. Thus discovered=records+errors can hold despite an unreadable or excluded subtree. File symlinks are not rejected before stat/read/hash.
