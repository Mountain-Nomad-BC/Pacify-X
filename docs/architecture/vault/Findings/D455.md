# Replay output limits and subscriptions do not bound all work or guarantee all deltas

**Historical finding; current closure not revalidated.**

replay reads/retains full history before selecting records after cursor and taking the latest limit; it does not indicate omitted earlier deltas. limit0 still scans history. wait_for_revision uses an instance-local condition, so another instance/process cannot wake it and new state may be observed only at timeout. Full replay cost follows the timeout and is not included in it.
