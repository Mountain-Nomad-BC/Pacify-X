# Environment consumer edges are lexical and can span root scopes

**Historical finding; current closure not revalidated.**

Environment key names across parsed files form one regex used against source text, including Markdown and JSON. Each matching key accumulates consumer rows across all roots; every declaration of that name receives those rows. semanticGraph uses global name-derived variable IDs and labels edges consumes-variable. These links can arise from comments, documentation or another root and do not prove runtime reads or per-root environment binding. Values and fingerprints are intentionally not retained.
