# Studio staging publication and reclamation are separate contracts

**Historical finding; current closure not revalidated.**

materializeSkillPackage registers custody before writing files individually to the target and verifies the complete tree before recording published. Failure retains uncertain resources. Reclamation requires a matching durable draft-create receipt, closed lifecycle record and exact inventory, then checks the moved tree before deleting the owned staging resource. This is distinct from canonical immutable revision publication.
