# CLI failure receipts do not cover every exception or final output failure

**Historical finding; current closure not revalidated.**

Only OSError, ValueError, KeyError, RuntimeError and JSONDecodeError enter failed-stage handling. TypeError, NameError/UnboundLocalError, KeyboardInterrupt and serialization errors can escape. Finally releases orchestration ownership; output serialization and print occur afterward, following any successful finish_release_stage. A stage can therefore finish before response delivery fails.
