# Count coverage does not itself enforce unique owner records

**Historical finding; current closure not revalidated.**

Registry envelope coverage compares sets of path/count_key pairs, allowing duplicate owner records to collapse. Schema, builder and consumer are checked only for nonempty values. The test adds record-count equality against discovered fields, but the validator alone does not. Discovery is top-level only with seven explicit exclusions; counts prove declared collection arithmetic, not record semantics.
