# Execution grant trigger differs from operation mutation vocabulary

**Historical finding; current closure not revalidated.**

operation_authority treats effects outside READ_EFFECTS, including process and workspace-write, as non-read. execution_contract.NON_READ_EFFECTS contains only write_workspace/install_tool/network/run_service/secret_access/migration/destructive. Given declared manifest and approved policy, the other recognized mutation spellings do not trigger its signed-grant checks or requires_verification. The outer owner gate still requires its IDs.
