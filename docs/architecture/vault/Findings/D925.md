# Transcript identifiers can collapse distinct source relationships

**Historical finding; current closure not revalidated.**

Source ID derives from first twenty digest characters, so identical bytes in different files have same source ID. Conversation ID is filename stem, so separate source names/extensions can share conversation. Writer/export dictionaries collapse those keys without uniqueness checks.
