# Abduction output limit does not bound subset enumeration

**Historical finding; current closure not revalidated.**

Hypothesis count is capped24, but max_combination_size is only clamped to the count, allowing every nonempty subset; max_candidates slices after all valid candidates are retained and sorted. Default size4 is smaller but caller can raise it. Nonmapping hypotheses are silently dropped, and stripped IDs differ from raw by_id keys, causing whitespace-ID lookup failure.
