# Explicit-path wrapper has a file-shape heuristic and independent final publication

**Historical finding; current closure not revalidated.**

Expected hashes treat len(inventory)==1 plus path suffix as a file. An extensionless file instead gains a duplicated basename, while a dotted one-file directory can lose its child name. Backend only compares expected keys that match actual inventory, so mismatched wrapper keys do not prove preplanned identity. Backend provides overlap/journal checks, but wrapper post-check or manifest failure can follow committed movement. Final manifest write is nonexclusive after an earlier existence check.
