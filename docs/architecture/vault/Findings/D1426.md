# Metadata duplicate grouping does not validate source hash identities

**Historical finding; current closure not revalidated.**

Planner groups str(item.get(sha256, empty)) without digest grammar or row uniqueness checks. Missing/default and null values differ; a null becomes the nonempty string None and can form a duplicate group. Duplicate source rows remain separate candidates. Repeated same plan output fails at exclusive directory creation.
