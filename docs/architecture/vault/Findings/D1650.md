# Deactivation clears some state but leaves other module globals

**Historical finding; current closure not revalidated.**

Lifecycle dispose clears selected timers/listeners/bridge/publisher; deactivate clears runtime/environment/lifecycle fields. It does not clear currentSnapshot, currentContextEnvelope, panel, dashboard view cache or activeHostRuns in this function. VS Code subscription disposal and process exit may close them elsewhere; same-module reactivation should not assume all state reset.
