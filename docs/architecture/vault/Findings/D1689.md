# Issue deduplication keeps the first blocking decision

**Historical finding; current closure not revalidated.**

Issue key includes source/code/context/message, but not severity or blocking. Duplicate occurrence/recovered fields merge while first blocking/severity/details remain. Probe supplies a nonblocking issue then the same blocking issue and retains nonblocking. Truncating message/context before key creation can also merge distinct long observations.
