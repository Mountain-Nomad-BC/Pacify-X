# Group status can discard stale index signal

**Historical finding; current closure not revalidated.**

resolve_test_groups computes index_current and current fingerprint. group_status compares stored receipt to that fingerprint but does not require index_current. A receipt matching changed inputs can report current while stored index is stale. Direct group execution separately rejects index_current false; full-profile/preflight status consumers do not repeat that check.
