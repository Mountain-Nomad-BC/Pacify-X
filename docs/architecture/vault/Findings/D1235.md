# Operator guard and mutation are separate APIs

**Historical finding; current closure not revalidated.**

CLI exposes guard-work as explicit read_snapshot plus guard_work_admission call. Other mutation commands directly append and do not invoke guard themselves. JSON payload may come from unbounded stdin or arbitrary existing file. This interface assumes host orchestration supplies prior authorization/governance; actor flag alone is not proof.
