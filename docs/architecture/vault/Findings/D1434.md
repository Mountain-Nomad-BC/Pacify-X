# Mining workflow definitions preserve order but do not execute it

**Historical finding; current closure not revalidated.**

Five workflows declare assimilation, secure service release, retrieval readiness, failure/recovery and external tool lifecycle. Assimilation branches incompleteness/relationships/boundaries after inventory, derive waits on relationships/boundaries, certify waits on incompleteness/derive. Other chains are linear. Producer replaces the whole workflow registry and emits a JSON-shaped YAML projection; it does not schedule the steps.
