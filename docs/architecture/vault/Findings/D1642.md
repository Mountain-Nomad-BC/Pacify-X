# Environment lifecycle uses typed-target UI approval rather than another host prompt

**Historical finding; current closure not revalidated.**

Unlike native extension install/update/uninstall/rollback branches, environment execute and restore directly pass approved=true with exactTarget from the message to their manager. The dashboard owns typed target/acknowledgement interaction, while manager owns token/identity checks. These are distinct approval boundaries.
