# Greedy SimHash clusters are not pairwise or transitive equivalence

**Historical finding; current closure not revalidated.**

Each unassigned anchor collects later candidates within distance, then all are assigned. Members need not be close to each other and transitive neighbors can be split. Confidence is computed from configured max_hamming rather than actual measured distances. Large same-prefix buckets can require quadratic comparisons.
