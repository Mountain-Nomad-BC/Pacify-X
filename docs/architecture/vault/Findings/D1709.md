# Proxy flags and denial sentinels are not network containment

**Historical finding; current closure not revalidated.**

Launch environment sets HTTP(S) proxies to dead loopback and NO_PROXY loopback after billing-key filtering. Sentinel checks only uppercase proxy strings; clients can ignore proxy environment or use other protocols. Native helper and runtime fixture invocations use nonBillableEnvironment rather than the same proxy wrapper. No network attempt was made by this audit.
