# Loaded dashboard bridge and navigation registry are not the controller implementation

**Historical finding; current closure not revalidated.**

The HTML loads 20-bridge.js and 40-surfaces.js, which define reusable modules. Controller constructs its own VS Code wrapper and visible/advanced arrays and registers its own message listener. The helper spread allows payload.type to override its first argument, but no controller use was found, so that helper behavior is not asserted as a production routing fault.
