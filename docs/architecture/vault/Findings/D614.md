# Native body identity and returned text are separate observations

**Historical finding; current closure not revalidated.**

Hash helper accepts raw bytes or newline-normalized text, and hydration opens body again afterward. Concurrent change can make returned content differ from checked hash. Preserved query records derive a new current body hash rather than authenticating original custody manifest.
