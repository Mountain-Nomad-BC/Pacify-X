# Calculation-bearing Foundry export mismatches its producer contract

**Historical finding; current closure not revalidated.**

CalculationPackage defines equation and normalized_dimension as a string. export_foundry_candidate reads item.expression and converts item.normalized_dimension with dict. Nonempty calculations therefore encounter an attribute mismatch before a usable candidate export. Existing bridge tests compile no calculation specs and do not cover this branch. Source-established mismatch, no product execution performed.
