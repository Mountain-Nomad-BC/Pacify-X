# Source manifest does not close complete loaded-byte identity

**Historical finding; current closure not revalidated.**

currentSourceManifest hashes only source_refs declared by the matrix, before browser work. It rejects outside lexical paths and leaf links, but does not reject linked ancestors or bind all preview/controller/harness assets. There is no final source equality check. sourcePath splits the first colon, so Windows absolute references are not supported.
