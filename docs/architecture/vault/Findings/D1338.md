# Sanitized archive identity can collide and old maps remain

**Historical finding; current closure not revalidated.**

Sanitization collapses path separators, control characters, drive syntax, colons, source terms and parent markers. Hazard sets deduplicate sanitized names, and map IDs hash sanitized root/path, so distinct originals can collapse or overwrite one map. No old map cleanup occurs when an archive disappears.
