# Retained discovery freshness differs by consumer

**Historical finding; current closure not revalidated.**

Host memory-only refresh updates currentEnvironment but skips shards; MCP and dashboard subject queries still call stored readers. On a stale stored snapshot, environments deactivates active rows; the graph route returns captured graph properties unchanged with a freshness label. Consumers must interpret that observation metadata rather than treating active graph properties as current liveness.
