# Native server directory custody is checked only at startup

**Historical finding; current closure not revalidated.**

Config is read once for command token comparison and reread inside serve. Request JSON files are globbed/read without per-file link, size, filename-sequence or stable identity checks; existing result files suppress requests. Stop is any stop.json existence. Config/secret shape is not independently validated by serve. These are local same-directory trust assumptions.
