# Signed transfer receipts are not bound to the bytes copied

**Historical finding; current closure not revalidated.**

Four signed references require transfer ID, source/destination project, producer/type/freshness and accepted result. No package content digest is compared. import_transfer checks both paths lie inside workspace, not that they belong to the named projects, and hashes actual content after copy. A receipt for the same transfer/project IDs does not by itself identify those copied bytes.
