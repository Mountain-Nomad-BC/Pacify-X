# Coordination result limits apply after full event and memory reads

**Historical finding; current closure not revalidated.**

tailJsonlDetailed reads/parses the full file before slicing up to MAX_EVENTS; readCoordination requests smaller tails after that work. memoryRecords reads all layer/session JSONL files and sorts all matches before slicing. A 100-record API limit therefore does not bound filesystem bytes or parser memory. Malformed event suffixes are reported and mutation checks reject degraded parse health.
