# Governor slot release does not establish producer termination

**Historical finding; current closure not revalidated.**

_drain races the producer promise against AbortSignal. Abort rejects the race and finally decrements pool.active, removes the entry and drains the next work, even if a noncooperative producer is still running. dispose signals entries without joining them. This bounds governed waiting slots; physical threads/processes need their own shutdown proof. Existing deadline tests use cooperative producers.
