# Sanitizer text replacement and multi-file operation are not transactional

**Historical finding; current closure not revalidated.**

Each text file uses a same-directory temporary, copied stat and os.replace; there is no file/directory fsync or concurrent-identity recheck. Finally retains a failed temp by move, which can itself fail and mask the original error. Later rename errors are outside the text-error catch. Earlier rewritten/renamed files remain changed if a later file fails.
