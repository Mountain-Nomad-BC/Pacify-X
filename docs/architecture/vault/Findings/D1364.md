# Included source traversal is less strict than excluded metadata traversal

**Historical finding; current closure not revalidated.**

Ordinary excluded metadata walk retains scandir errors and rejects a linked boundary. Main included os.walk has no onerror, and later nonregular/disappeared paths can silently continue. Included symlinks increase a skip count but do not enter the inventory digest like nested excluded symlinks do. An opaque boundary is selected before the ordinary symlink check.
