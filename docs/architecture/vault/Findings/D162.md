# Registration error can become an inaccurate spawn-failure receipt

**Historical finding; current closure not revalidated.**

ProcessSupervisor catches OSError from the entire manager.spawn_owned_process call and reports not_started/tree_closed true with no resource ID. ResourceManager can raise that error from ledger upsert after Popen has started. The wrapper does not recover the child handle on this path; the existing missing-executable test covers only failure before child creation.
