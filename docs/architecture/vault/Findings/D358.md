# Signed learning readers and recovery enforce different history rules

**Historical finding; current closure not revalidated.**

The normal learning reader verifies signed event/hash chains and typed nested state, but recovery additionally binds event pipeline identity, state sequence, initial evidence state, directory identity and legal transitions. Proposal history has a similar normal-reader versus recovery difference. A valid signature does not itself establish every lifecycle invariant.
