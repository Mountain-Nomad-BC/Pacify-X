# Editor source token can be consumed before a later failed recheck

**Historical finding; current closure not revalidated.**

Skill next-version consumes source-selection token, then verifies requested identity/version, rereads package, checks hashes/provenance and asks backend for allocation. A mismatch/read/backend failure can consume the token without producing allocation, requiring new selection. Catalog lookups are limited to first 100 matching results and require exact uniqueness.
