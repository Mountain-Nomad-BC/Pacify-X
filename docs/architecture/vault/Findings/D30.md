# Theory proposal requirements exceed the fields checked by its validator

**Historical finding; current closure not revalidated.**

Induction advertises distinctness, held-out generalization, failure boundary and operational value as required evidence. validate_proposal currently computes the pass rate from supplied held-out passed flags and checks truthy distinctness evidence. It does not explicitly validate failure-boundary or operational-value fields, execute held-out cases, or promote a theory.
