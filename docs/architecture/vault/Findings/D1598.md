# Native input focus and expiry checks are not atomic with SendInput

**Historical finding; current closure not revalidated.**

Request expiry is checked before up to 0.75 seconds of focus recovery. Root birth is checked before recovery and foreground PID is observed before SendInput; focus can change in that gap. The helper verifies sent key-event count but cannot prove the intended dialog consumed or committed the action.
