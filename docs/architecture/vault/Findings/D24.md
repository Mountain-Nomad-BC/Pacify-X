# The workflow scheduler is richer than its standalone adapter set

**Historical finding; current closure not revalidated.**

Workflow Studio has scheduling, branches, approval, joins, retries and typed outputs. The inspected workflow_worker currently executes identity, increment, double, fail and sleep. It rechecks signed task/executor/grant bindings and runs declarative validation checks. Broad catalog composition is therefore not evidence that arbitrary skills execute through this worker.
