# Decay and restoration have opposite nontransactional failure windows

**Historical finding; current closure not revalidated.**

Decay writes canonical head then learning event/head; restoration writes learning event/head then canonical head. Pipeline CAS failure can follow decay mutation. Restoration head failure leaves a canonical pipeline that the decayed-only revalidation method cannot normally retry; final write also reuses a pre-transition head without canonical CAS. These interleavings are source-inferred, not reproduced here.
