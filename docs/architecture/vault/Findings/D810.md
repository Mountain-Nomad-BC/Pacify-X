# Trust JSON rejects many non-JSON forms but is not a resource bound

**Historical finding; current closure not revalidated.**

Serializer rejects nonfinite numbers, cycles, unpaired surrogates, object accessors and nonplain objects; arrays use element access and do not apply equivalent descriptor checks. Recursive serialization has no depth/byte cap before result size checks. Sorted string keys use JavaScript ordering; cross-language parity must use matching canonical rules.
