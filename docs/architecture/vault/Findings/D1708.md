# Storage isolation is inferred from chunk-local stdout text

**Historical finding; current closure not revalidated.**

storageBoundaryObserver recognizes shared-storage database paths only within each stdout chunk and accumulates paths without a cap. Split log text can be missed; classified paths are lexical rather than physical. Recognized in-memory or owned path plus no observed external path becomes verified, not an independent inspection of all host storage.
