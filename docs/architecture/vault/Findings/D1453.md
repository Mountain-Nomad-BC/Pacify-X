# Group scheduling can stop before collecting the full selected denominator

**Historical finding; current closure not revalidated.**

Parallel-safe futures are consumed with future.result without a per-group exception conversion, followed by serial groups. An exception in one future causes pool context shutdown and exits before later serial execution; other completed receipts may exist without a complete result report. Ordinary returned failed executions do not take this exception path.
