# Studio commit and UI delivery are separate result boundaries

**Historical finding; current closure not revalidated.**

The host rechecks version allocation and source identity before saving. After the backend call, it validates the commit receipt. Invalid receipt yields commit-outcome-unverified; valid commit plus failed cleanup, refresh or notification yields warnings while preserving committed identity. This is more precise than treating a dashboard error as proof that saving failed.
