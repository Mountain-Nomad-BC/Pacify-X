# CLI successful evaluation does not always mean an approved decision

**Historical finding; current closure not revalidated.**

Claims-only admission/outcome evaluation, authorization simulation and security/hook authority decisions can return valid=true and exit0 for a denied or nonauthoritative decision. Authoritative admission/outcome paths use explicit disposition codes; retry maps allowed to valid. Default output without valid is treated as successful. Consumers must use the command-specific contract.
