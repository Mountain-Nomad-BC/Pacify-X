# Inventory text structure is bounded lexical evidence rather than parser semantics

**Historical finding; current closure not revalidated.**

Text detection uses a 64 KiB sample, suffix/MIME or UTF-8. Structure extraction uses regex headings, fences, links, command prefixes and declaration lines over text below a size threshold. Normalized digest uses sanitized casefolded whitespace; SimHash takes at most 100000 tokens. Large text remains text with empty structure.
