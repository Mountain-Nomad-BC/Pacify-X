# Progress retention has a read/hash interval and no lifecycle chain

**Historical finding; current closure not revalidated.**

Readers cap file size and validate schemas/states but then hash by a separate file read, not the parsed bytes. Profile reader accepts empty input and checks no profile start/end pairing, timestamps or owner; last record is copied without field sanitization. Host writer whitelists pid/ready_after_ms but appends by path without rejecting a linked existing target.
