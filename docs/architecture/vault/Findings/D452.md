# Bus publication trusts state and route metadata before extending history

**Historical finding; current closure not revalidated.**

publish recovers WAL and reads state but does not invoke head or replay before appending. It checks route ID/tier while ignoring route status, consent, effect classes and component/owner identity. Registry is validated then reread, cached by size/mtime/ctime. Event IDs may repeat and receipt path is built from raw ID, so existing receipts can be replaced and dot segments can target other paths within the WAL allowed root. WAL containment does not imply receipt-namespace confinement.
