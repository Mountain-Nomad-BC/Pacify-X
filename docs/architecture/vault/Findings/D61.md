# Cleanup reclaimed counts include retained local quarantine

**Historical finding; current closure not revalidated.**

Cleanup can move an unchanged staged tree to local quarantine after recycling fails. The final confirmedResults set includes that state when calculating resources_reclaimed and bytes_reclaimed. Those counters describe disposition of the original cache location, not measured disk-space recovery. Errors with disappearance remain disposition-uncertain.
