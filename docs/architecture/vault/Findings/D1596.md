# Native input retry and numeric bounds have limited validation

**Historical finding; current closure not revalidated.**

Only the exact activation-refusal error is retried, with at most two numeric attempts and a new sequence each time. NaN/fractional option values are not explicitly rejected; NaN maximumAttempts can skip the loop and throw null. TTL is caller numeric input while server independently restricts lifetime to ten seconds.
