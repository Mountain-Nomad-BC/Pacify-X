# Intake full-tree snapshots actually identify regular-file projections

**Historical finding; current closure not revalidated.**

snapshot_tree records files only, hashes whole files after separate stat and omits empty directories, links as links, device/inode and permissions. File symlinks can be followed and enumeration/read work has no count/byte bound. Equality is therefore file-projection identity, not full filesystem snapshot or a lock against concurrent changes.
