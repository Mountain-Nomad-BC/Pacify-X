# Legacy map wrappers expose different validation and exit contracts

**Historical finding; current closure not revalidated.**

Build forwards traversal budgets/exclusions/incremental mode and exits zero when the runtime returns, without checking a valid field. Validation opts into freshness only with --fresh and maps valid to exit status. Query forwards top-k and exits zero on a returned result. Their runtime owners, not wrappers, enforce operational behavior.
