# Probe output is bounded after subprocess capture

**Historical finding; current closure not revalidated.**

subprocess.run captures complete stdout/stderr before joining and truncating to 4096 characters. Individual deadlines bound direct waits, not aggregate work or descendant lifetime. Scrubbed environment does not impose network or filesystem isolation; read_only/not-used fields are declarations.
