# Cached executable resolution does not bind executable bytes

**Historical finding; current closure not revalidated.**

The resolver checks platform layout, directory/sentinel/executable plain-file state and marker owner/schema. It does not verify retained_versions includes requested version, sentinel contents, executable digest/signature/version or all ancestor realpaths. Darwin has no supported layout despite a macOS browser lane elsewhere.
