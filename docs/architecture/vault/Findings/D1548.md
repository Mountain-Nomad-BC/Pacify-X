# Sanitizer and cache tests leave several operational failure paths open

**Historical finding; current closure not revalidated.**

Fixtures cover ordinary preview/apply, canonical expansion, long names, collisions, named exclusions, preflight read failure and single-level cache recovery. They do not cover nested cache targets, content drift between preservation and mutation, copy-byte verification, linked source rename or failed final receipt. Some sanitizer tests preserve a sibling directory outside their TemporaryDirectory context. None were run here.
