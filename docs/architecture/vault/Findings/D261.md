# Startup configuration does not validate every policy field

**Historical finding; current closure not revalidated.**

Config enforces exact safety booleans, positive integer budgets and nonnegative retries, but leaves default effect and effect collections without vocabulary/type validation. Missing retry_requires_new_evidence becomes false; ID/version/mode and deferred set may be empty. Actual budget and policy enforcement remain consumer responsibilities.
