# Deployment planner accepts non-finite numbers and truthy strings

**Historical finding; current closure not revalidated.**

Numeric validation rejects negative values and booleans but not NaN/infinity. Architecture, streaming, privacy and remote flags use bool coercion rather than boolean types. Confirmed supplied strings false for architecture_supported and remote_fallback_allowed produce native feasible and remote conditional under fitting memory; no effects occur.
