# Dashboard readiness is distinct from successful rendered snapshot

**Historical finding; current closure not revalidated.**

ready resolves panel readiness before awaiting initial snapshot publication. openDashboard waits at most fifteen seconds, then forces snapshot/deep link. Timeout throws without disposing panel here; later callers can await same ready promise. Panel disposal releases origin and detaches creates, while other asynchronous handlers may continue and encounter delivery errors.
