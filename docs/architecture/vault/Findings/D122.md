# Fallback retains primary model and attachment metadata

**Historical finding; current closure not revalidated.**

Policy wrapper allows fallback by adapter ID after validating declared fallback metadata. Gateway replace() changes invocation_id and adapter_id only; model_id, revision and attachment remain primary. Returned policy outcome also uses primary request metadata, and exact receipt check expects the primary model ID. Thus a fallback declaration naming a different model is not itself applied by this path. No live fallback was executed.
