# Process timeout and interruption closure differ

**Historical finding; current closure not revalidated.**

Process wait timeout attempts Windows tree termination or POSIX group termination and verifies the leader has stopped. Other BaseException paths close the log but do not terminate the child. POSIX leader polling is not a complete descendant inventory. Owner wrapper itself does not register its launched processes in resource lifecycle.
