# Malformed JSON lines can be discarded without a parse-error receipt

**Historical finding; current closure not revalidated.**

ReadBuffer catches SyntaxError from JSON.parse and continues to the next line. Schema-invalid messages reach transport.onerror, but syntax-invalid lines disappear at this boundary. Diagnosis and client retry must not assume every rejected request generates a typed error response.
