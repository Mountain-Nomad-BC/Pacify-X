# Cache subprocess test isolation is platform-dependent and unbounded

**Historical finding; current closure not revalidated.**

runIsolatedCacheOwner changes TEMP/TMP but not HOME/cache override; cache owner uses home-based root on Linux. Its subprocess has no timeout or nonbilling environment filtering. The test writes fixed cache-layout fixtures and removes a temp directory afterwards; it is not evidence of universally isolated cache behavior.
