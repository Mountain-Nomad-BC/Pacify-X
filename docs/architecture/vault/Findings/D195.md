# Finalizing workflow cancellation bypasses worker-exit publication gate

**Historical finding; current closure not revalidated.**

request_lifecycle directly transitions finalizing to cancelled on cancel/stop and changes terminal_target. It does not verify worker exit or update run receipt there. The normal observer finalizer returns early for already-terminal state, so terminal label in this shortcut does not establish normal closure evidence. Existing test uses synthetic finalizing state without a live worker.
