# Core navigation risk can differ from declared contract risk

**Historical finding; current closure not revalidated.**

navigation_index assigns R1 when effects subset read_local and R2 otherwise, ignoring contract risk. Skill adapter instead uses declared risk when present. Routing the same capability through different metadata adapters can therefore expose different risk information; adapter calls do not themselves invoke validate_registry.
