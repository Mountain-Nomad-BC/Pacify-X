# Incremental map facts trust prior cache and ignore changed text limits

**Historical finding; current closure not revalidated.**

Mapper reuses previous file-facts row when declared sha256 matches current full file hash and adapter_version matches. It does not validate prior receipt/fact semantics and does not include max_text_bytes in reuse key. Increasing scan limit can therefore preserve earlier truncated facts; modified cache facts can be resealed when their stored source hash/version still match.
