# Content-addressed extraction is not an atomic multi-file publication

**Historical finding; current closure not revalidated.**

Destination mkdir uses exist_ok=false, so repeated identical input fails rather than verifies/reuses existing output. Index is created exclusively, but later summary/candidate/duplicate files are separate writes; interruption leaves a partial directory that blocks a same-digest rerun. CLI returns zero even with text-read failures.
