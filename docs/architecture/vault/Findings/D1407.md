# Sort receipt fingerprints can follow different source bytes

**Historical finding; current closure not revalidated.**

Sampling and benchmarking precede input stat and full SHA read, so mutable input can diverge from sampled records. Sample hash includes only keys and ordinals, not payloads. Output can alias the input and overwrite it despite dry_run=true, because no separate output identity is enforced.
