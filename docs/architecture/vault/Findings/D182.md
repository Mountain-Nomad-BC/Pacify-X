# Effect grant validation depends on complete caller target inventory

**Historical finding; current closure not revalidated.**

Network hosts, secrets and writable targets are checked only when supplied. A network effect does not itself require a nonempty host inventory. Nonce and idempotency are nonempty/same-value checks with no consumed store; repeating a valid same-key grant can pass. Actual target enumeration, replay policy and execution interception belong to callers.
