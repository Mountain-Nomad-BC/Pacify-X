# A valid Doctor report can describe a blocked system

**Historical finding; current closure not revalidated.**

compose_doctor_report requires exactly eight sections and valid states/remediation links, then selects blocked before degraded before healthy. It sets valid=True for the report, operable unless blocked, and ready/certification_ready only when healthy. The inspected tests assert these differences. Those flags belong to diagnostic composition and do not issue a release certificate.
