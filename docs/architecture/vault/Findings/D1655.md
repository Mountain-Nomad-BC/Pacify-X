# Save detachment preserves host commit ownership

**Historical finding; current closure not revalidated.**

Close while a save is active records a detached request and sends detach rather than release of proof owned by the host commit. Matching detached result refreshes catalog and history but does not clear or replace the current editor. The detached request set is bounded to 64, so very late results can become unmatched.
