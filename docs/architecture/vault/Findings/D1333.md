# Freeze helper captures one file view rather than an immutable full topology

**Historical finding; current closure not revalidated.**

Snapshot includes paths recognized as files with content hash, size and mtime, omitting directory and other entry identity. File links can dereference content, casefold-only sorting can tie, and no scan budget or second matching snapshot is enforced. Output under the scanned root changes future manifests; timestamp also changes output bytes.
