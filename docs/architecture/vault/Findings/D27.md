# Owner registries and runtime reachability answer different questions

**Historical finding; current closure not revalidated.**

Primitive/effect registries validate which owner is canonical. A caller search locates whether and where an operation is actually invoked. Tests establish assertions in source, while exact installed operational receipts establish exercised behavior. The atlas retains these evidence levels instead of treating one as a substitute for all the others.
