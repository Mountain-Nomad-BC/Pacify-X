# Sanitizer traversal materializes excluded subtrees before filtering

**Historical finding; current closure not revalidated.**

A complete rglob list is sorted deepest-first without file/byte/depth/time limits. Exclusions are applied in later loops, not traversal pruning. changed_nodes is built without exclusions and later adds renamed-node descendants to preservation, so excluded names can still be read/copied when selected by name transformation.
