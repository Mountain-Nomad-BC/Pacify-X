# Full map validation omits checks present in quick receipt validation

**Historical finding; current closure not revalidated.**

validate_project_map hashes only entries supplied by receipt.file_sha256 without requiring every required file be listed; it does not verify receipt self-hash or recompute map_revision. It checks fact/inventory path sets without matching each fact source hash. project_map_status quick mode additionally verifies receipt self-hash and required hash names, but not file bytes. Thus full and quick checks are different sets rather than a strict stronger/weaker pair.
