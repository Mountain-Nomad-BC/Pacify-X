# Extension receipts distinguish adapter uncertainty but can themselves fail after effects

**Historical finding; current closure not revalidated.**

Phase receipts flush a temporary file then rename, with directory fsync only off Windows. A write outside the per-candidate try or terminal write failure aborts the loop/return after prior effects; no restart reconciler is defined here. Callback temporary-file removal errors are suppressed.
