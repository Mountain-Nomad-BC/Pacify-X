# Profile health and prerequisite failure can diverge

**Historical finding; current closure not revalidated.**

Pre-builder baseline failure is returned and ignored; builder outer catch is usually bypassed because timedProfile swallowed the exception. Studio candidate watchdog can return only an attempted prefix; later candidates never enter its denominator.
