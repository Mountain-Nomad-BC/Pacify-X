# Selected host action receipts are latest in-memory observations

**Historical finding; current closure not revalidated.**

durableHostActionTypes controls storage in activeRuntime.lastHostActionRequest/Result, not a persistent journal. Only one latest request/result survives; no per-request idempotency check or history exists. Setting a terminal result before reply preserves it across later delivery failure, but extension restart loses this local memory.
