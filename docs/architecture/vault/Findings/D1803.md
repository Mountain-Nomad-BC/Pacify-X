# Snapshot selection can return older matching state after a newer contradiction

**Historical finding; current closure not revalidated.**

selectLatestMatchingInstalledSnapshot retains the latest predicate match separately from latest observed snapshot. If a newer snapshot fails the predicate, it still returns the earlier match and callers may accept it. Pure probe shows revision1 success selected after revision2 failure. Existing test covers only stale-then-good ordering.
