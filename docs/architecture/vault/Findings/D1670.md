# Pending host actions are bounded memory with latest snapshot replay

**Historical finding; current closure not revalidated.**

Browser retains at most 64 pending host actions and matches direct reply operation/request. Snapshot can replay latest host request/result into globals and clear a matching pending item. These globals and host fields are memory, not a persistent complete action journal; no per-action timeout exists here.
