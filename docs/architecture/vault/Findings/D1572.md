# Fixture packaging is deterministic within the chosen runtime inputs

**Historical finding; current closure not revalidated.**

The builder fixes UTC ZIP time, sorts names, deflates at level 9, stores CRC32 and produces two fixed identities. It directly overwrites VSIX files then publishes receipt, without transactional pair replacement or rollback; compression/runtime differences are not cross-version reproducibility proof. Import executes all builds.
