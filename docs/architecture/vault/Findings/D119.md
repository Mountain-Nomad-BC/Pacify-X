# Work result publication precedes causal finish state

**Historical finding; current closure not revalidated.**

execute writes the result cache before _record_finish updates state.json. If finish-state recording fails, the owner records failure/raises while a concurrent joiner may already consume the result cache. Pool and operation locks are released sequentially; a pool-release exception can prevent operation release. These boundaries need separate recovery evidence; no failure injection was executed for the report.
