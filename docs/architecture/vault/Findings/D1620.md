# Host model output budget is checked after full stream accumulation

**Historical finding; current closure not revalidated.**

Each stream is consumed into responseText, streamedText and responseParts before countTokens compares accumulated output to a clamped cap. Tool-call argument content is not counted as responseText output tokens. Requested maxOutputTokens itself is constructed before clamp. A noncooperative/large stream can exceed memory/time expectations before the check.
