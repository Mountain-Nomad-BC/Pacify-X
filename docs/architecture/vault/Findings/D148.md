# Handoff consumption checks fewer acknowledgment fields than construction

**Historical finding; current closure not revalidated.**

acknowledge_handoff checks receiver ID/revision when creating the value. consume_handoff checks accept, acknowledgment digest and packet ID/hash, then validates packet receiver against supplied context; it does not compare acknowledgment receiver fields, schema or time again. Hashes are unkeyed and persistence is exclusive creation, not independently authenticated receiver approval.
