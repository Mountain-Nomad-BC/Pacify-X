# First persistent snapshot return bypasses the normal short TTL refresh branch

**Historical finding; current closure not revalidated.**

snapshot accepts matching persisted metadata up to24h old and immediately returns persistent-hit. Its ordinary cache TTL is5s..5min, but the first restore does not invoke that branch or mark refresh_pending. A later snapshot request can initiate stale-while-revalidate. Matching source identity is not equivalent to current dynamic provider/coordination observations.
