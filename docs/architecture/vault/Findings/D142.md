# Deterministic worker setup and cleanup have failure paths outside terminal handling

**Historical finding; current closure not revalidated.**

_execute_session transitions running before creating the task workspace/signing task outside its guarded supervisor try. After supervision it parses last stdout JSON without asserting an object, then reclaims task content before terminal transition; cleanup errors raise first. These source paths can leave nonterminal state requiring owner reconciliation, rather than guaranteeing immediate terminal publication on every exception.
