# Append fallback may perform recovery before requested event is admitted

**Historical finding; current closure not revalidated.**

_load_append_base_unlocked is invoked under lock before preparing new requested event. Its recovery can write a receipt and alter final delimiter/torn suffix even if later payload validation fails. project/write_snapshot also invokes recovery; the read-only head/snapshot APIs do not.
