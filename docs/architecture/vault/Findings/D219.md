# Duplicate model IDs can separate ranking winner from selected record

**Historical finding; current closure not revalidated.**

select_model_attachment ranks model capability rows but selects next eligible_rows item matching winner model_id. eligible_rows includes rows that rank_models later rejects for unavailable/context/traits/privacy. Duplicate IDs can therefore bind the first different row rather than the row that earned winning score. No uniqueness check exists here.
