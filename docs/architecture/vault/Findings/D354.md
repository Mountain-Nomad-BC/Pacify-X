# Direct decay can mutate the canonical head before rejecting approval

**Historical finding; current closure not revalidated.**

measure_learning_reuse writes the suspect canonical head before calling _transition_learning, which checks approved, actor and revision CAS. Thus a direct method call with approved false can reach a write before denial when decay criteria pass. Studio API consumes host proof before dispatch, so this is a direct-controller boundary, not an established unauthenticated Studio route.
