# Local server start verifies self-consistency without repeating plan construction checks

**Historical finding; current closure not revalidated.**

start accepts a ServerPlan whose unkeyed hash matches and whose declared model/executable bytes match, but executes plan.command without reconstructing it from executable/model/host/port fields. It does not repeat allowed roots or numeric bounds. A caller-created self-consistent plan can therefore have command semantics different from plan_server output. This is a caller authority boundary observed in source, not an executed exploit.
