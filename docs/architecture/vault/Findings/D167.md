# WAL before-image guard begins after caller intent was computed

**Historical finding; current closure not revalidated.**

WAL compares current targets with before/after images captured during commit. It can detect later external writes, but without an owner precommit validator it accepts a newly captured value as before even if the caller computed its after value from an older read. RetentionManager constructs JsonWal without a validator, confirming the boundary documented in D160.
