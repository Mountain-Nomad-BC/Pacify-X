# Environment writer and reader accept different dataset sizes

**Historical finding; current closure not revalidated.**

writeDataset serializes and writes data without a maximum size check; readDataset rejects any shard larger than8MiB before returning records. Thus a produced snapshot can be validly indexed yet have an unreadable graph or subject shard; a small API page limit does not avoid that check because pagination follows full loading. No large-dataset reproduction was executed.
