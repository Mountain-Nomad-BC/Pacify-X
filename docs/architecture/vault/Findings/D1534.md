# Historical deletion evidence is late and accounting is not physical reclamation proof

**Historical finding; current closure not revalidated.**

The owned-cache script aborts on error and writes no final receipt after partial deletion. The other two catch per-target failures but retained targets may already be partly changed. Counts use logical file lengths; C-drive free-space differences are host-wide and can include unrelated activity or another target volume. Receipts are final direct writes without a durable per-effect journal.
