# Workflow trace helper tests and browser code have different owners

**Historical finding; current closure not revalidated.**

The CommonJS projectWorkflowTrace helper is imported by its unit test, while the dashboard uses a separate projectWorkflowTraceResult implementation. Both inspect workflow/version/run identity and conflicting hashes, but a helper test is not evidence that the actual browser implementation executed.
