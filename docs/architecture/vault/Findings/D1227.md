# Segment validation verifies content equality but not every manifest range claim

**Historical finding; current closure not revalidated.**

Validator checks manifest digest, segment byte/hash/count, combined exact legacy event equality, reducer validity and global legacy/head identity. It does not compare per-segment first_sequence/last_sequence/predecessor/head fields or enforce declared segment_event_limit against rows; manifest schema and read bounds are also not validated here.
