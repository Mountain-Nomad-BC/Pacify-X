# Audit bundle wrapper delegates completion to clean export

**Historical finding; current closure not revalidated.**

The wrapper requires existing output directory and VSIX, checks package version, calls clean_source_export and checks exit code before hashing resulting archive and writing sidecar. It has no own subprocess timeout or rollback for sidecar failure; wrapper valid=true depends on the child contract rather than independently reopening all archive evidence.
