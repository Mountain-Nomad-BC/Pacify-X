# Exact recovery branch trusts supplied flags and can accept an empty list

**Historical finding; current closure not revalidated.**

Candidates with no missing paths are accepted when every supplied recovery row has exact_match truthy; bytes are not rehashed. With an empty sources list, both all checks pass vacuously. For candidates with some missing paths, other sources outside that set are filtered out without the exact-recovery check.
