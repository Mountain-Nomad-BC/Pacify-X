# Commissioning preview reads complete skill bodies and can reuse stale inventory

**Historical finding; current closure not revalidated.**

_skill_registry reads every active/admitted body to derive hash/byte metadata, though project scaffold copies only metadata. _existing_inventory trusts saved JSON without current-tree comparison. Metadata-only startup and commissioning preview therefore have different I/O scopes; the latter is not purely compact catalog loading.
