# Support consolidation infers behavior from names

**Historical finding; current closure not revalidated.**

Unassigned support paths group by artifact kind and slugged filename, with pack qualification only for certain kinds. Cross-pack contracts can therefore consolidate by stem. Behavior, targets and test filenames are generated strings, and the selected canonical owner is not checked for current existence or semantic equivalence.
