# Detached worker last-resort diagnostics are discarded by launcher

**Historical finding; current closure not revalidated.**

_retain_publication_failure tries two filesystem paths then os.write(2,...), with a comment that launcher supervises stderr. launch_studio_worker sets stderr DEVNULL. The unit test mocks os.write and proves the call, not retention through the actual launcher. When both diagnostic writes fail, this final fallback is discarded on this path.
