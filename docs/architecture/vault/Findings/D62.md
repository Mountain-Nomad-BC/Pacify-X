# Rollback identity custody is not an available rollback artifact

**Historical finding; current closure not revalidated.**

Extension uninstall retains the exact prior version before native dispatch. Rollback consumes custody only after that version is observed again; command failure, wrong version or pending reload leaves it retained. When no hash-bound local VSIX exists, actual restoration still depends on an available source accepted by VS Code.
