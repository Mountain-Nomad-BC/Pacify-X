# Operational bootstrap retains ready receipt after later failure

**Historical finding; current closure not revalidated.**

The bootstrap awaits activation, actual command registration and command return, writes ready with wx, then waits up to fifteen minutes for a sentinel. Catch writes failed only if receipt does not exist, so release timeout leaves the earlier ready record. Activation/command awaits have no local timeout and sentinel contents/identity are not checked.
