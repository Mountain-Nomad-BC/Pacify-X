# Sequential child finalization can prevent later cleanup

**Historical finding; current closure not revalidated.**

Finally writes sentinel, terminates walker, writes progress, requests native stop, awaits/races helper, terminates VS Code then publishes result. Some awaited termination/progress/receipt writes are not independently caught; an early failure can skip later cleanup and child-result. Parent timeout/process owner may still reconcile independently.
