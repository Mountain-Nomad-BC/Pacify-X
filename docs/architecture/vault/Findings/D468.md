# Authoritative quarantine snapshots are not bound to the bytes that failed parsing

**Historical finding; current closure not revalidated.**

After parse failure, quarantine takes two snapshots and a third immediate snapshot but does not compare them to original parsed bytes. A repaired file arriving before those snapshots can be moved as corrupt. Resolving source/quarantine before link checks can erase original symlink spelling. Registry artifact_kind joins destination directories without identifier validation; no final destination containment check follows that join.
