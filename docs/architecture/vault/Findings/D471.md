# Intake sequence and reopen semantics have gaps

**Historical finding; current closure not revalidated.**

Exclusive filenames include sequence plus event kind, so concurrent different event kinds can occupy the same sequence and later fail sequence validation. Events have no hash chain or authentication. close_intake chooses the last two snapshot events over entire history, not since latest open/reopen or matching alias, so unchanged prior-epoch snapshots can satisfy closure. Only actor string presence is checked; nonfinite stability window is not rejected.
