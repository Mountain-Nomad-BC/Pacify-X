# Atomic decision functions need a separate persistent owner

**Historical finding; current closure not revalidated.**

reserve_budget and atomic_work_checkout compute new records over caller-supplied snapshots. They contain no lock, durable read/commit or worker effect. These are separate from ProviderBudgetLedger and coordination claim persistence. Two callers can evaluate the same prior snapshot; a real persistence owner must serialize acceptance.
