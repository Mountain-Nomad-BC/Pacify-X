# Successful release preflight retains the certify claim for finalize

**Historical finding; current closure not revalidated.**

Authoritative preflight checks certify processing stage and claims certify once. On valid=true it reports completion_deferred_to release finalize and clears only the local variable, leaving the durable claim. Finalize can reuse matching active certify claim or claim one if absent, then delegates actual artifact finalization.
