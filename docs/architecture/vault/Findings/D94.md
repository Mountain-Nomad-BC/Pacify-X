# Coordination read routes can publish corruption evidence

**Historical finding; current closure not revalidated.**

readAuthoritativeState copies raw corrupt, invalid-shape, workspace-mismatched or hash-mismatched state into quarantine and writes a receipt before throwing. Several MCP read-only tools call it through readCoordination or readMemoryTelemetry. tool_conflict_status catches that error and can return a normal result after the evidence write. The missing-store nonpersisting read test does not establish no-write behavior for damaged existing state.
