# Surface capture checks labels rather than image bytes

**Historical finding; current closure not revalidated.**

Surface capture requires exactly eighteen named records, navigation_active, matching capture surface and first/deep screenshot status captured. It does not read screenshot files, inspect image hashes, timing, visibility or dimensions. The test uses status-only screenshot objects and is a predicate fixture, not rendered evidence.
