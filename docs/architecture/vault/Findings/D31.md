# The deterministic harness does not execute a natural-language objective

**Historical finding; current closure not revalidated.**

agent_harness_worker authenticates the task and runs the explicit sha256, json-keys or bounded-delay tool calls. Its result states model_invoked=False and records whether an objective was received plus its hash. The host-model path is where language-model invocation occurs. Treating these as one agent execution capability would conceal a substantial runtime boundary.
