# Package hash is emitted but excluded from host/source match

**Historical finding; current closure not revalidated.**

identityMatches compares version, asset hash, asset protocol and message schema, not package_sha256. Version comes from require(packagePath), potentially cached, while hash reads current disk. Equal selected assets/protocols can still yield a match across other package metadata changes.
