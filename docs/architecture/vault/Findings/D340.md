# Rollback backup rehash is not checked against original pre-promotion tree

**Historical finding; current closure not revalidated.**

Rollback verifies current canonical equals promoted_tree_sha256 and authenticates committed promotion journal. It then computes restored_sha from current backup contents and uses those contents as new canonical_source without comparing to promotion_manifest.canonical.before_tree_sha256. A changed but structurally valid backup can therefore be re-attested as rollback output. This source path has not been executed as a reproduction.
