# Text repair CLI does not enforce separate or immutable output custody

**Historical finding; current closure not revalidated.**

Pure repair returns bytes, but CLI accepts arbitrary output and receipt paths without alias checks, allowing input/mapping overwrite or one output replacing another. Receipt binds input/output hashes and version text, not mapping bytes. The test checks only the pure helper leaving input unchanged.
