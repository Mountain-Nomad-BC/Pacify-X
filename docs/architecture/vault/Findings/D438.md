# Coverage gate trusts summary counts and suffix path matching

**Historical finding; current closure not revalidated.**

Validator trusts num_branches/missing_branches without nonnegative or missing<=total checks; zero total gives100percent. An empty class/module policy can pass. It matches exact or suffix module paths rather than source hashes, and accepts any nonempty context name somewhere in the file. Aggregated class coverage can hide a poorly covered module; per-module floors are not imposed.
