# Validation cache is keyed to snapshot identity at publication time

**Historical finding; current closure not revalidated.**

Validation runs against current configured engine root, then stores result under validationCacheKey(currentSnapshot) after completion. If snapshot/root changes while validation runs, this local code does not compare the validated source identity with that later snapshot key. Cached result is reused without a TTL in this owner.
