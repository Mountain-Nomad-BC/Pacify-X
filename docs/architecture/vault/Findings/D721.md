# Fleet live advance and reconstruction enforce different timestamp rules

**Historical finding; current closure not revalidated.**

Canonical replay requires increasing heartbeat timestamp for nonstale advances; _advance does not enforce that monotonicity before persistence. Equal/backward live times can persist while later lagging-state replay rejects equivalent advance. Future age clamps to zero.
