# Nonobject additional issues are silently discarded

**Historical finding; current closure not revalidated.**

dedupeIssues skips values that are not objects. The isolated child pushes native helper termination/exit failures as strings, so those explicit failure signals vanish. A pure evaluator probe with the actual helper failure string returns completed. Other independently classified failures may still block, but these strings cannot.
