# Large-snapshot fallback can reuse the stale artifact that caused replay

**Historical finding; current closure not revalidated.**

After append-base checkpoint failure, fallback returns full replay with predecessor=None. Publication subsequently rereads existing snapshot unbounded and, if at least 8MiB, uses it as delta base without requiring a verified predecessor. Corrupt JSON can raise after append; stale well-formed base plus only new appended rows can produce unreadable delta checkpoint. Source-derived path; normal forced-delta test uses valid base.
