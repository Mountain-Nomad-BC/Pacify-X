# Logic result hash excludes appended queries

**Historical finding; current closure not revalidated.**

KnowledgeBase.infer hashes atoms/derivations before reason appends the queries list. The nested result_sha256 therefore does not bind the complete returned result. Facade adds a separate hash of that result. max_rounds bounds rounds only; rule/fact count and retained support remain unbounded.
