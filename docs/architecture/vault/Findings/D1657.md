# Information modal metadata changes before replacement is accepted

**Historical finding; current closure not revalidated.**

showInformationModal assigns shared title/record/copy fields before showModal checks whether a live Studio editor may be replaced. A refused replacement can therefore update shared metadata while leaving prior DOM present. Separately, operationalCardResult and operationalInventoryResult explicitly closeModal before showing uncorrelated details, which can detach a newer in-flight save.
