# Governed execution binds memory and handoff hashes without forwarding their contents

**Historical finding; current closure not revalidated.**

preview_governed materializes memory and validates acknowledged handoffs, but _resolved_preview returns their hashes. execute_governed_plan includes those hashes in request/receipt and calls execute_agent_plan with task plan, placement, run ID and CPU/GPU callbacks only. The integration test CPU lambda returns a constant answer without consuming context. This establishes receipt binding; content injection requires a separate caller path.
