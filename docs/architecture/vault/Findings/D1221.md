# Atomic publication applies per file rather than across all checkpoint files

**Historical finding; current closure not revalidated.**

Writer uses exclusive prepared filename, flush/fsync, os.replace and directory fsync where supported, then removes prepared file. Multiple files publish separately; optimistic readers retry three times and then report unavailable. A failure during prepared-file cleanup can also propagate after replacement.
