# Host prerequisite failure can lose its restoration record

**Historical finding; current closure not revalidated.**

Preparation makes changes before returning the scenario, so throwing during preparation can leave the caller without baseline state. A repeated preparation result is discarded. Activity settings restore writes original bytes without intermediate compare-and-swap and may overwrite concurrent edits; root/link ownership is not fully established here.
