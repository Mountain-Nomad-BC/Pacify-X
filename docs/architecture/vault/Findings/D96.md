# MCP retained resume packet bypasses packet hash and freshness checks

**Historical finding; current closure not revalidated.**

writeHandoff binds packet.sha256 and verified_state_hash, and its Markdown instructs consumers to verify. pacify_resume_handoff only reads current coordination to get the packet path, then calls generic JSON loading. It does not verify packet.sha256 or equality with current coordination state, so the source route can return a stale or resealed-independent packet. Fresh taskHandoff is a separate derived route.
