# Graph authority validates output digest but not current source revisions

**Historical finding; current closure not revalidated.**

Graph manifest requires source revision strings to look like SHA-256 but does not compare them with current source bytes. Output digest and two-directory graph inventory are checked. Reconciliation updates graph/source hashes without rebuilding graphs, so these functions alone cannot prove output was derived from those sources.
