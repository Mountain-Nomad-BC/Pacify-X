# Environment refresh uses a partial on-disk extension view

**Historical finding; current closure not revalidated.**

The wrapper scans user .vscode/extensions and one Windows local installation builtin path. First encountered publisher/name wins across versions, directory order is not sorted before deduplication, and isActive=false is supplied for every extension. It does not query the active host or additional portable/Insiders/remote installations.
