# Revision preservation does not compare pre-save predecessor hashes

**Historical finding; current closure not revalidated.**

predecessor_preserved checks original owner and hash shape in the predecessor read after save. It never compares those hashes with pre-save allocation/source/candidate hashes. Changed predecessor content can therefore satisfy preserved if selected owner remains. Reopened editor comparison checks owner/identity/version, not complete saved content bytes.
