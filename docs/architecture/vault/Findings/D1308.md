# Control and cohesion apply are not one atomic operation

**Historical finding; current closure not revalidated.**

The release driver requires check-control, check-cohesion, apply-control, apply-cohesion in exactly that order. Control events use append batches while cohesion uses a separate WAL. A failure after control apply can leave control changes committed without cohesion closure; driver final status separately checks both denominators.
