# Navigator can return unrelated selectable records for a nonmatching query

**Historical finding; current closure not revalidated.**

Each selectable record gets+0.25 even without lexical/fuzzy/dense evidence, and only nonpositive total scores are discarded. Thus an unmatched query can produce nondegraded results if such records exist. Selectable includes reference_only/reference/formula, not just admitted/executable; default selectable_only is false. Exact governed alias reason does not prove freshness or authority.
