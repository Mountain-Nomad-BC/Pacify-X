# Studio atomic JSON replacement has a different durability contract from WAL

**Historical finding; current closure not revalidated.**

write_json_atomic writes a unique prepared file then os.replace without file/directory fsync or cleanup on replacement failure. Its name describes replacement visibility, not the staged-image recovery protocol in JsonWal. Durable controller signs event and head, but each uses this separate helper.
