# Readiness callback and started-event failures can bypass startup cleanup

**Historical finding; current closure not revalidated.**

After ResourceManager spawn, start runs readiness_probe and _append started outside a try/finally. Exceptions in either leave the normal timeout termination branch unreached. An event-head write failure may occur after the durable event append, producing a different partial state than a probe failure.
