# Coverage policy errors and class validity can diverge

**Historical finding; current closure not revalidated.**

Class valid depends only on complete module matches and aggregate percentage; missing dynamic contexts can make overall valid false while the class still reports valid true. Exemptions are shape-checked and counted, not applied to branch totals. Coverage and policy are read again for hashing after evaluation, so concurrent mutation can bind different bytes from those evaluated. Release caller adds report generation and release-root/hash checks, but helper alone does not prove execution.
