# Optional accelerator discoverability is treated as executor availability

**Historical finding; current closure not revalidated.**

_discover_hardware_details adds cupy/cudf/tensorrt backends from find_spec alone and may mark CUDA executor available. Those specs are checked even when probe_libraries false. Torch/ONNX child probes provide stronger observations, but arbitrary chosen backend still must support the actual workload. hardware_report valid remains true with unavailable probes.
