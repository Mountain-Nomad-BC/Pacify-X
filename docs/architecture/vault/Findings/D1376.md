# Skill alias and vendor routes have different target checks

**Historical finding; current closure not revalidated.**

All declared specialty and alias targets are checked against catalog IDs, even unrelated entries, but empty lists pass and delivery/disposition labels are not validated. Vendor-prefix matches emit two hardcoded owner names without checking their catalog presence. Metadata can therefore complete without an active executable owner.
