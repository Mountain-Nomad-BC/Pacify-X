# External owner evidence is a portable assertion rather than current external-file verification

**Historical finding; current closure not revalidated.**

Extension/MCP missing owners may be satisfied by an accepted local receipt with exact owner-path key and SHA shape. The external root need only be a nonempty string; actual external bytes, receipt producer, timestamp and result are not verified. Planned unadvertised routes skip acceptance validation, so such receipts can be considered without that hash-validation path. Local owner checks hash current bytes but do not prove those bytes implement the route.
