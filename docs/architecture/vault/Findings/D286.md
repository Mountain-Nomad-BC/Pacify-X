# Workspace rebuild and normal replay interpret some lifecycle fields differently

**Historical finding; current closure not revalidated.**

Normal session replay verifies renewal lease ID and pending operations remain unresolved after session-revoked. Rebuild renewal omits lease-ID check and counts session-revoked/expired operation IDs completed; revision also increments for renew/revoke unlike normal registry update path. Rebuild is therefore a separate interpretation, not exact replay of every normal projection counter and pending-intent rule.
