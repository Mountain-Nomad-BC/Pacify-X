# Configuration acknowledgements have weaker branches than host-action receipts

**Historical finding; current closure not revalidated.**

Enterprise response matching uses operation and Boolean(master_enabled), not exact request/status, allowing absent state to resemble disabled. Approval may return a read acknowledgement before final disposition validation. Fault marker errors are operation-matched rather than request-bound and the config marker differs from the consumed host-action marker.
