# Ledger digest cache trusts device inode size and mtime

**Historical finding; current closure not revalidated.**

Fingerprint caches whole-ledger digest by device/inode/size/mtime_ns and extends it from admitted append bytes. Same-identity same-size content mutation with restored mtime can evade this cache; source has no post-hash fstat consistency check. Existing same-length mutation test changes file normally and does not restore metadata. This edge is source-derived, not reproduced here.
