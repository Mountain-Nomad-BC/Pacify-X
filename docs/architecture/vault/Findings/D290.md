# Empty event set bypasses retained ledger head checks

**Historical finding; current closure not revalidated.**

validate_event_ledger checks head only when event_paths is nonempty, so removing every event yields valid empty chain even with old authority files. read_event_tail returns missing before checking head. Existing tests remove one event from two or rewrite an event while leaving head; they do not cover total event-set loss. No files were removed for this report.
