# Provider accounting can commit before terminal event publication fails

**Historical finding; current closure not revalidated.**

_invoke_once commits successful settlement before publishing completed. An exception at that publication escapes with accounting already settled and no response receipt returned. Adapter failures burn reservation before publishing failed; failure-event publication errors can replace the original sanitized failure. Budget and event owners have separate WAL transactions.
