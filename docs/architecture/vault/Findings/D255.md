# Project retrieval relations are entity links rather than the full project graph

**Historical finding; current closure not revalidated.**

_retrieval_index accepts dependency_graph and architecture but does not consume their edges. It links files to contained symbols/routes and shared configuration/integration entities. Service IDs are based only on service name; equal names across Compose files collapse in graph/index dictionaries. Whole-file documents span the full scanned line count and can produce broad hydration ranges despite a small top_k.
