# Contained child failure is interpreted through fresh group receipts

**Historical finding; current closure not revalidated.**

An exited, tree-terminated, nontimed-out child can have valid=false/exit1 without immediately aborting refresh. The owner checks receipt freshness, then returns all fresh failed groups. Full profile still runs cross-group checks and forces final valid=false if that failure list is nonempty. Noncontainment and unresolved new resources fail earlier.
