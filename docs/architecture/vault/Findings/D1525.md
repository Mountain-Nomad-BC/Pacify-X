# Sanitizer collision naming checks availability without reservation

**Historical finding; current closure not revalidated.**

Overlong components use a deterministic name digest and limited suffix; collisions try widening source-name hash suffixes. Availability is checked before rename rather than reserved atomically, and preview does not reserve generated names. Path-change output hashes the original relative path and stores a sanitized target string; it is not a complete actual-path journal after ancestor renames.
