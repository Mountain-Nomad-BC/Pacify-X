# Numerical and dimensional foundation helpers have narrower guarantees

**Historical finding; current closure not revalidated.**

Numeric shift rejects nonfinite series but does not require a finite threshold; NaN threshold can suppress drift and finite large values may overflow intermediate variance. For nonconstant baseline it measures only mean shift, not changed variance/distribution. Dimension checks int-coerce exponents before algebra, so fractional exponents can be truncated; steps are independent declarations, not linked to an expression or units.
