# Information value uses supplied post-test utilities and calibration coerces outcomes

**Historical finding; current closure not revalidated.**

VOI validates probability sums and finite nonnegative costs but receives best_expected_utility per outcome rather than solving posterior decisions or running tests. Calibration converts outcomes with int before binary checking, so fractional values can be truncated into accepted0/1. Collection sizes/bins have no upper bound.
