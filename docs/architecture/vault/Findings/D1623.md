# Tool call receipts are collected in memory before final host completion

**Historical finding; current closure not revalidated.**

At most eight requested calls are permitted and each exact binding is policy-checked. Started receipt is appended before invoke; failed invocation annotates error and propagates all collected receipts. Completed input/result hashes are unkeyed observations held in memory until backend completion; no per-call durable journal is written here.
