# Activity cancellation and repair have narrower meanings

**Historical finding; current closure not revalidated.**

reconcileStaleOperations emits a cancelled activity record without killing a process. repairActivityIntegrity retains exact pre-repair backups, reconstructs predecessor hashes and reseals parsed records. Its postcondition proves internal consistency of that repaired chain, not original event authenticity. recordActivity appends JSONL before atomic state publication; those two files are not one atomic transaction.
