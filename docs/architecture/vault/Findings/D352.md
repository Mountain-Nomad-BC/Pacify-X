# Revision tree hashing and import classification have bounded scope assumptions

**Historical finding; current closure not revalidated.**

revision_for_path resolves the requested root target but does not independently contain every nested file symlink and reads full tree contents without count/byte bounds. Import inventory uses stored packaged surface membership, AST static imports and current interpreter stdlib names, omitting dynamic imports. Distinct source denominators must be retained when interpreting revision or dependency coverage.
