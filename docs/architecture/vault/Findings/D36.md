# Semantic selection has several distinct contracts

**Historical finding; current closure not revalidated.**

The cheap semantic index builds profiles and descriptions, while navigate computes weighted lexical evidence and an exact-alias boost. Independent discovery allows candidate metadata; later routing makes active/admitted and policy-filtered items selectable. Working-set dependency recursion rolls back a bundle when it cannot fit. These operations rank and explain metadata; they do not invoke a model or prove task feasibility.
