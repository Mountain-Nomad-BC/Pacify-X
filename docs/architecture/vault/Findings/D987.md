# Unmanaged readiness launches validation and parses truncated combined output

**Historical finding; current closure not revalidated.**

Unmanaged path invokes runtime.cli validate and requires exit success plus valid true JSON. Probe combines stderr with stdout and truncates before JSON parsing, so otherwise valid noisy/large output may be rejected. Nested malformed metadata or nonobject payload can escape handled exceptions.
