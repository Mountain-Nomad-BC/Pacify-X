# File identity text structure and hash can describe different versions

**Historical finding; current closure not revalidated.**

Inventory stat, sample read, optional full text read and final streaming SHA are separate operations without before/after identity verification. Concurrent edits can produce old size/structure with new hash. Full-tree freeze likewise stats before hashing each file and does not lock or compare a second snapshot.
