# Generic record immutability is narrower than full revision immutability

**Historical finding; current closure not revalidated.**

write_versioned_record accepts kind/identity/version separately from model and does not compare them with model fields. Existing revision replay compares only record.json with normalized envelope; undeclared sibling files are not inspected. Agent/Workflow specialized publishers supply additional full-tree and receipt checks, so this generic helper alone must not stand for them.
