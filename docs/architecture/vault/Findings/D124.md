# Provider observed effects are registry-derived labels

**Historical finding; current closure not revalidated.**

Gateway writes identical declared and observed effect arrays from adapter registry mode. Local mode reports model only, although included local HTTP adapters make loopback POST requests. This is an effect-label convention, not independently measured I/O; the local-effects test uses a fake adapter.
