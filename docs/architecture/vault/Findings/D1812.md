# Plugin failure cleanup can uninstall a preexisting fixture

**Historical finding; current closure not revalidated.**

The initial absent check happens after manager entry actions. If it fails because fixture v1/v2 already exists, catch may uninstall that version as failure cleanup without a created-by-this-run marker. Final absent inventory also leaves retained rollback custody, so it is not complete initial state restoration.
