# Certified supersession is decided before expiry and actor filtering

**Historical finding; current closure not revalidated.**

Vault retrieval_records builds superseded IDs from all certified/trusted latest records, then filters individual records by expiry and actor ACL. An expired or inaccessible certified correction can suppress a prior record even when that correction is not returned. The standalone candidate_memories helper is broader still: it collects supersedes from every supplied record before filtering. No live retrieval reproduction was run.
