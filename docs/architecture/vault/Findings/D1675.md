# Workflow local graph edits use closed typed semantics

**Historical finding; current closure not revalidated.**

Supported task adapters are explicit deterministic operations, not arbitrary agent execution. Retyping a node clears all incident edges; removing a binding leaves references for later validation rather than silently rebinding them.
