# Closed intake movement can complete before failing without a journal

**Historical finding; current closure not revalidated.**

The dedicated move helper performs repeated file equality checks then mkdir/shutil.move and post-move snapshot. It has no intent journal, failure compensation or recovery receipt; an existing source manifest name is discovered only after move when exclusive manifest creation fails. Destination-inside-source is not explicitly rejected, and destination existence can change between check and shutil.move. No quarantine event updates the intake ledger.
