# Historical reconciliation input hashes are later observations

**Historical finding; current closure not revalidated.**

Source inventory paths and rule owner paths have no physical containment guard; lexical parent traversal and links can resolve outside the root. Most helpers parse input first and hash the path later, so mutable bytes can produce a digest unrelated to parsed data. Direct output writes and optional require-complete exit policies do not provide atomic or immutable custody.
