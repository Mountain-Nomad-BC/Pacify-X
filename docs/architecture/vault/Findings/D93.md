# Sanitation primary bounds do not constrain its separate secret scan

**Historical finding; current closure not revalidated.**

build_sanitation_summary bounds and hashes its first corpus, then calls scan_secret_shapes(root) through a separate os.walk/full-file-read path without explicit count/byte ceilings. That scanner applies shared external-scope checks to directory names, but not file-specific mutable exclusions to file entries. Consequently primary corpus bounds/hash do not alone identify or bound all credential-scan inputs. Matching review classifications also remain supplied dispositions, not independent credential verification.
