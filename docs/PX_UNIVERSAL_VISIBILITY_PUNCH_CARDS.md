## Current frontier

The product is reopened. Historical certification evidence is stale for the changed tree and cannot establish current operation. Work is now ordered by real product dependency: installed host identity and message contracts; live sidebar/dashboard routing; Studio persistence and lossless editing; graph/project intelligence; activity/memory/knowledge truth; runtime/provider/plugin actions; then live visual interaction review. Certification remains explicitly paused by the user.

GPU placement remains CPU-authoritative. Hardware presence alone does not justify acceleration; the current product must show a compatible executor, correctness parity, current benchmark advantage, observability, bounded VRAM, and CPU fallback before any real-device speedup is claimed.
