## Executive finding

PACIFY-X does not have one current deployable authority. The Python runtime, the installed VS Code extension, the external development extension, project-management state, operation-coverage registry, punch-card evidence, and Codex integration describe different product states. The dominant failures are therefore provenance, lifecycle, and authority-boundary failures rather than a single slow function.

The Python metadata startup is approximately 0.30 seconds. The installed extension spends approximately 40.3 seconds activating before failing on an undeclared proposed API. It leaks a recursive workspace watcher and partially registered listeners, leaves an active coordination session, and continues appending observational activity. `PX Doctor` separately claims a dry run while acquiring and rewriting WAL locks and invoking recovery.
