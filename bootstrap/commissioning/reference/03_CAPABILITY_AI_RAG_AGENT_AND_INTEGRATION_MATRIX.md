# Capability, AI, retrieval, agent, and integration matrix

For each requested capability, record the user outcome, inputs, outputs, source of truth, effects, permissions, failure behavior, evidence, latency, cost, and acceptance checks.

Use deterministic software when it is more accurate, safe, cheap, or maintainable. Justify AI, retrieval, and agents independently. For retrieval, define exact/semantic/graph/structured strategies, permissions, citations, freshness, conflicts, and deletion propagation. For agents, define identity, tools, containment, approvals, memory, audit, budgets, recovery, and stop conditions. For integrations, map direction, ownership, schema adaptation, retries, idempotency, and disagreement resolution.
