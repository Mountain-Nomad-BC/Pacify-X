# Governance, security, accessibility, and operations

Classify the deployment and consequence level. Define identity, roles, authorization, secrets, supply-chain controls, network boundaries, logging/redaction, privacy, retention, backup, recovery, deployment gates, rollback, monitoring, incident ownership, and evidence retention.

Assess accessibility for every official deployment using the applicable current requirements, audience, jurisdiction, procurement rules, input methods, assistive technology, themes, contrast, text sizing, motion, keyboard behavior, and verification plan. Optional reading aids are not substitutes for accessibility standards.

No planning artifact authorizes installation, external access, account creation, production connection, migration, destructive work, security-sensitive testing, or deployment.
