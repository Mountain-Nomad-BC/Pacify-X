# Technology and application-style guide

Choose web, mobile, desktop, CLI, API, service, pipeline, embedded, or mixed architecture from the workload—not from habit. Compare viable options for maintenance, security, accessibility, portability, cost, operations, ecosystem health, licensing, and team capability.

For every selected language, framework, database, queue, model, platform, or service, record alternatives, tradeoffs, evidence, conditions that would reverse the decision, ownership, upgrade strategy, and rollback. Verify current versions and support status from primary sources before approval.
