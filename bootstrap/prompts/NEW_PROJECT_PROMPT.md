# New project workspace prompt

You are operating the Engineering Loop Bootstrap at `<BOOTSTRAP_DIR>`. The governed multi-project workspace is `<WORKSPACE_DIR>` and the new project name is `<PROJECT_NAME>`.

Keep startup metadata-only. Before applying effects, show the relevant preview, scope, and rollback. Proceed with reversible effects inside the user-approved task scope; ask only before an irreversible destructive action.

1. Validate the framework with `agentic-engineering-os-px doctor` and `agentic-engineering-os-px validate`. If the installed command is unavailable, use `python -m runtime.cli --root "<BOOTSTRAP_DIR>" ...` from the source checkout.
2. Preview `agentic-engineering-os-px workspace init --workspace "<WORKSPACE_DIR>"`. Explain that the project drop root will be `<WORKSPACE_DIR>/projects`, central state will be under `projects_tracking`, cleanup will use `repo_quarantine`, and reusable sanitized assets will use `shared_capabilities`.
3. Apply the same command with `--apply` when the preview is reversible and inside the user-approved task scope.
4. Preview `agentic-engineering-os-px workspace create-project --workspace "<WORKSPACE_DIR>" --name "<PROJECT_NAME>"`, then apply with `--apply` when it is reversible and inside scope. Do not create the project anywhere except `<WORKSPACE_DIR>/projects/<PROJECT_NAME>`.
5. Run `agentic-engineering-os-px workspace status --workspace "<WORKSPACE_DIR>"`. Require a valid central registry, a project-local workspace binding, an isolated tracking root, and an isolated memory root.
6. Allocate a stable `<AGENT_ID>` and `<SESSION_ID>` for this agent/team. Activate the generated project ID with `agentic-engineering-os-px project activate --workspace "<WORKSPACE_DIR>" --project-id "prj_<PROJECT_NAME>" --agent-id "<AGENT_ID>" --session-id "<SESSION_ID>"`. One session may hold only one writable project, while separate sessions may operate separate projects concurrently. Read both `projects_tracking/PROJECT_MANAGEMENT.md` and the project's `PROJECT_MANAGEMENT.md`.
7. Run `agentic-engineering-os-px project-check --project "<WORKSPACE_DIR>/projects/<PROJECT_NAME>"` and `agentic-engineering-os-px startup --project "<WORKSPACE_DIR>/projects/<PROJECT_NAME>"`. Startup must report zero hydrated skill bodies. Review its read-only tooling assessment, separate observations from recommendations, and present any proposed installation/configuration effects for explicit approval; never install from the startup result itself. If a standalone report is useful, run `agentic-engineering-os-px tooling assess --project "<WORKSPACE_DIR>/projects/<PROJECT_NAME>"`.
8. Copy `bootstrap/commissioning/questionnaire-template.json`, complete it with facts/assumptions/unknowns kept separate, set `mode` to `new`, preview `agentic-engineering-os-px brief --project "<WORKSPACE_DIR>/projects/<PROJECT_NAME>" --questionnaire <answers.json>`, and apply it only after approval with `--apply`. Do not treat the generated placeholder project brief as accepted requirements.
9. Run `agentic-engineering-os-px lifecycle status --project <PROJECT_DIR>` and follow its next-stage contract. For each approved goal, use `working-set`, then run `agentic-engineering-os-px hydrate --skill <selected-id>` for one selected skill body, execute a bounded step, checkpoint it, and release task-specific context. Never hydrate the entire library.
10. Use `agentic-engineering-os-px workflow list` and JSON requests passed to `agentic-engineering-os-px workflow run --workspace "<WORKSPACE_DIR>" --request <request.json>` for registered project-stream workflows. Preview first; use `--apply` only after approval.
11. Ingest project-local evidence with `agentic-engineering-os-px memory ingest`; promote candidate memory through `validated` and `certified` using `memory transition` with evidence; create evidence-backed corrections with `memory correct`; retrieve only through `memory search` while that project is active. Pass the same `<AGENT_ID>` and `<SESSION_ID>` to every memory command. A correction must not suppress certified memory until the correction is certified.
12. Before leaving the project, run `agentic-engineering-os-px project release --workspace "<WORKSPACE_DIR>" --session-id "<SESSION_ID>" --context-reset-confirmed`. A same-session switch to another project must use `project activate ... --session-id "<SESSION_ID>" --context-reset-confirmed` and must deny old-project access.

Stop closed on workspace ambiguity, a path outside `projects/`, registry or binding drift, an expired/foreign lease, missing approval, a cross-project memory attempt, an unapproved effect, or missing completion evidence.
