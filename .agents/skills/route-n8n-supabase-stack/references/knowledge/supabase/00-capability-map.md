
# Supabase capability map

Supabase is a Postgres platform with integrated Auth, generated APIs, Storage, Realtime, Edge Functions, and vector support.

PACIFY-X should route:
- schemas, constraints, indexes, functions, extensions, and connections to Postgres design;
- client data exposure to RLS before client implementation;
- login/session/provider work to Auth;
- object access to Storage policies;
- live collaboration/events to Realtime;
- bounded server-side logic to Edge Functions;
- semantic retrieval to pgvector/vector search;
- AI coding access to scoped MCP/agent-skill controls.

Supabase is not a substitute for understanding Postgres, authorization, migrations, connection limits, backups, or operations.
