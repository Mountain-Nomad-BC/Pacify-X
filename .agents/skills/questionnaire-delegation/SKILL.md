# Questionnaire Delegation

Use when the current user cannot authoritatively answer required decisions.

For each question include why it matters, allowed answer shape, examples, dependencies, and the consequence of no answer. Separate required from optional. Avoid asking for facts PACIFY-X can retrieve itself.

Generate a machine-readable companion schema so returned answers can be validated and merged into the decision map. Mark respondent identity, authority scope, timestamp, and confidence.
